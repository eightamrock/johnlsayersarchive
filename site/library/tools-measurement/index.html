Measurement and tools

This topic collects threads about software tools used for measuring, modeling, and calculating acoustic and physical properties of home and project recording studios. Two tools dominate: SketchUp, a free 3D modeling program used to sketch studio layouts and room designs (including shared example files such as a small studio model and a basement studio build), and Room EQ Wizard (REW), a free acoustic measurement package used to analyze room response and guide treatment decisions. Alongside these are a number of member-built calculators and spreadsheets distributed as Excel or HTML5 files, covering room modes, wall bounce reflections off the front and side walls, reverberation time, Helmholtz resonator tuning, and transmission loss through wall assemblies, as well as the Harman Mode Calculator for identifying problematic room resonances. Together these threads document the practical toolkit members used to plan, measure, and evaluate studio spaces before and after construction, and to troubleshoot acoustic problems using data rather than guesswork. Readers new to studio design will find both the software recommendations and the calculation methods behind them explained across these posts.
