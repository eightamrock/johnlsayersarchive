Hi guys! It's been a while since i last posted! Exterior building work at the house is nearly complete and i can soon start work on the studio... WOO HOO! lol I have some queries about doors! The recording space isn't huge, it's approx 6mx3.4m and out of that i'm using 1.5mx3.4m for the vocal booth. I would like to use a glass sliding door inbetween the booth and control room. The type of door i'm talking about is the upvc patio door type of things. Does anyone here have any experience with these kind of doors in a recording environment? I want to try and minimise the amount of noise transfer between the control room and booth during the recording process but i also want to be able to see the artist in the booth. Due to the size of the room etc. I really want a sliding door option so that i can take back space that would have been taken up by having to use a conventional door. My desk is approx 2.4m wide so i won't be left with a lot of room for a door anyways. I've tried searching on google for specs on the pvc doors but there's not a lot of info in terms of the acoustic properties. Any info would be greatly appreciated. Kang.
jwl3 July 2008#2
If it were me, I'd reconsider using a vocal booth inside a studio that small. For more on why, see this article: http://realtraps.com/art_booth.htm That said, if you do use a booth with a sliding glass door, most places will use 2 of them (for a 2-leaf construction). Like everything else, isolation will depend on mass and airtightness. Get doors with the thickest glass you can, and make sure the seals are good.
