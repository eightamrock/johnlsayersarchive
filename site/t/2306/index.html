Tockley12 September 2004#1
Firstly, thanks to John and the gang for a really great forum. I've been addicted to this place since I first discovered it. I've been working on a design for a little while now and recently started going round in circles.I thought it might be a good time to step out and (hopefully) get some feedback. The building is a standalone brick warehouse in an industrial area. The only annoyance is it has a take away shop (i.e milk bar) in the front corner. Floor is a concrete slab, the height to the lowest point of the roof support beams (edges- A frame type roof) is 4.4 m. It rises maybe another 50-60 cm's in the middle. We'll be either getting existing plans of the place from council soon, or having a draftsman measure it up.Construction will be directly on the slab. The floating floor thing came and went about the time we priced air con. So were doing a double frame on rubber type construction.Not ideal, but we're having some tests done next week to check out flanking transmission via the slab. The biggest concern is keeping noise out of the takeaway shop. We'd like to be able to track a 2 guitars, bass,drums type band live. We've settled on (after much debate) not having a window from control room to the live room. We also want to be able to leave enough usable space to add rooms down the track. First things added would be a machine room in the space between the control room and the east wall and an amp iso (closet) between the 2 iso's on the back wall.Essentially we're trying to build what we can afford now, get up and working, then refine it down the track. So the wall I've hit is placement of the iso's.We'd like a live main room with the smaller iso for a bass cab and bigger iso for guitar cabs or as a secondary deader drum room. Any ideas would be very much appreciated. Any other general comments regarding the overall layout would be great too (i.e. it's way off base!) Thanks again to John, I hope it's ok to use the Smartdraw files that are so obviously his creation.And sorry about the metric measurements! Cheers and thanks.

John Sayers13 September 2004#4
Brent - the inside out wall system is a space saver for people with small rooms - i.e. bedrooms etc. In your case you have good sized rooms so the easiest way is tro build normal walls and froame your inside angled walls off them. Yup - I'd reconsider the window - they are not hard to build and not expensive if you hunt around for the glass. cheers john
