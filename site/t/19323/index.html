I want a 2 room studio. HELP
Control room plus live room? For that space, I'd say the only reasonable layout is to use the top room as the control room, oriented facing left (towards the 11'6" wall), and the other room can then be your tracking room.
I need the tracking room to be Super quiet. That matters
But it is already built, right? As Ralph said: if it is already built but it is not quiet enough for your needs, the then only real way to fix that is to "un-build" enough of it that it can be isolated properly. Isolation (often incorrectly called "soundproofing") is not something that can be added to a room that already exists (or at least it can't be added at reasonable cost). Rather, it has to be designed into the original room plans before the room is built. There are some things that you can do to improve isolation, but first we'd need to know hoe much isolation you already have, and how much you need. So it's time to break out the sound level meter, and measure some levels! :)
Just need to know where to put the dividing wall etc.
The best option seems to be where you have the dotted line, but once again, don't build anything more until you first figure out how much you have to "un-build" first. Once that is in place, then you can incorporate that new wall into the isolation system of both rooms. - Stuart -
