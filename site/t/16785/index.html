Hello! I am seeking help with the layout planning of my studio. The main purpose of this studio is Producing, Tracking(vocals) and Mixing. No live room needed. I did the best I could with sketchup to create the actual space layout(first time I use it). I used the actual measurements to create the .skp file but if you need me to post them differently or an actual blueprint layout, let me know.
File not preserved: 1502 Studio Design.skp
What I would like for this space is: 1. Control Room a. with Production Station b. glass window to Vocal Booth c. suffit loudspeakers (powerd 15" JBL's) d. Sofa 2. Vocal Booth 3. Bathroom(in the far left corner) 4. Small Equipment/Storage Room The most important thing to me is to get the best acoustics possible for this space. As shown on the .skp file, I want to leave a 1 car space on the left side of the garage. So walls can be built around the parking space and use the rest of the garage for the studio. Don't worry about the existing walls, they can be taken down if necessary. Im not very concern about my neighbors complaining about noise because the garage is part of the basement and my neighbors houses are not that close to mine. But nonetheless, I am willing to do all the soundproofing necessary to get the best acoustics possible. I am very concerned about the ceiling height(acoustics wise) which is 7'9". Plus the ceiling drops 10" by 2'6" wide and it runs thru the middle of the garage ceiling horizontally from wall to wall.(please see the attached .skp file to see what I mean) This drop was made originally to hide the A/C duct lines. My budget is $2,000 to $3,000 but will not stop the project if more is necessary. Please have in mind that I will personally be doing all the construction with the help of family members which are professional contractors. So basically the budget will be spend in materials not in labor. If there is any more information I can provide to help you help me, let me know. I will really appreciate all the help and ideas I can get from all of you! Thanks in advance!!!
