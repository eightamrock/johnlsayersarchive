Colorblind13 February 2007#1
Hi all, I want to begin treating my control room, starting with the first reflection points. I realize that there is sound emanating from the entire monitor enclosure, but I'm still a little unclear. When using the "mirror" technique, should I be placing absorption anywhere that I can see any part of the monitor enclosure, or only those spots where I can see the actual speakers (horn, woofer)? Can someone clarify? Thanks, C
jwl13 February 2007#2
Well, think of it this way. Use the mirror technique to see the drivers from the listening position. That should be the center point. Then, for your absorbing panels, the bigger you make them, the more you'll be able to move your head around and still benefit from the absorption. In other words, yes, I'd put up an absorptive panel everywhere you can see any part of the speaker. And then some.
