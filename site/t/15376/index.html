gullfo13 December 2010#2
welcome! as a general rule: super chunks in the corners for bass trapping and scattered absorption on the walls and ceiling to break up the flutter echoes and make things diffusive without making it sound dead or dull. use 2'x2'x4" (600mm x 600mm x 100mm) rigid insulation covered in cloth in a 3'x3' (900mm x 900mm) checkerboard pattern on the ceiling and using 2'x4'x4" (600mm x 1200mm x 100mm) rigid insulation absorbers on the walls - vary them slightly in height and leave opposite sides of the room untreated (stagger the arrangement). treat all the cloth to be fire retardant. you can make frames using 1x4 (19mm x 100mm) or 1x1 and some metal angles to create frames of the same size but with open sides (more work, lighter, slightly more absorption). keep the floor concrete or tile or wood. maybe some scatter rugs. if you want to get the drums or amps up off the floor, some isolation risers can be constructed using 2" rigid insulation (cover in cloth optionally) on the floor and lay on 2x 3/4" (19mm) MDF with the seams staggered. a top layer of 3/4" plywood for screwing in the drum kit hardware. this decouples the instruments from the floor pretty nicely.

gullfo14 December 2010#4
the decision to build an inner wall will depend on how much isolation you need. if you just need to treat the space then what i've described is a start. if you need more isolation and want an integrated approach using soffit mounted monitors and builtin trapping, angled treatments etc. then i'd suggest looking into inside-out walls as means of increasing the isolation and preserving as much space as possible - John's small studio is a good model to follow.
