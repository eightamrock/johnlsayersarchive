Hi, Design looks good. Do you need seperation between the control room and the live room? If yes, then you will have flanking issues. the control room needs to be completely seperate from the external brick walls. What are the dimensions? and what height can you build too? (2.9m ??) Are there any pipes or aircon ducts in the ceiling? Some answers. 1. The basstrap will work properly fitting the slots will glass wool or will be better to build some panel to hang inside the slots? -A slot trap will work fine will some loose glass wool in the cavity. 2. Like in the original project i have foreseen two slot resonator wall that may be work like Helmholtz resonator. Coul really i realize it with a pegboard as i found in this site? Peg board will not work as a helmholtz 3. What about the ceiling? It's not foreseen in the original project. How i have to realize it? I've to angolate it? How much? Will better if i build another solt resonator there? Draw a more detailed plan shown your studs and top plates. Don't worry about the interior finsh at the moment. Again what height can you go too?
