gullfo28 November 2007#3
14m3 is actually 495ft3 (which is volume rate not velocity...) some options for reducing the velocity include: a variable or low speed AC unit which can be set to the desired speed, and/or using a size change in the duct to cause the speed to reduce because you are expanding the duct.

gullfo16 January 2008#7
doubling the AREA of the duct reduces the air velocity by a factor of 4. 8" round duct is about 50sq in. 12" duct is about 114sq in. so going 4" more in diameter (if using round duct) effectively doubles the duct size. convert m3 to ft3 multiple m3 by 35.31467 9cmm x 35.31467 = 317.83203 cfm this may help also: http://www.engineeringtoolbox.com/air-d ... d_669.html
