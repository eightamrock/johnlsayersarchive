I've never built a desk before so I'm wondering if I should just buy a $4000 desk or build it myself. I have access to most of the tools and a little experience with woodworking. I honestly don't know where to start. Dimensions, which type of wood to buy, what's on the underside/inside the desk for the main weight support, legs, even how to make two pieces of wood stick together. I've got time to learn and I can take the build slow, I just need to know HOW to do it. If it's too much trouble and not worth it, I'll just shell out for an Argosy. Any input is appreciated.
