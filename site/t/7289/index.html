AJ - I'm not sure what you are trying the achieve here. You appear to want to have two control rooms, one for tracking and one for mixing upstairs. Whynot go with one proper control room - this will allow for extra space for rehearsals etc. You really need to read up some more because you don't appear to understand WHY the control room walls are splayed. Here's what you should read up on. http://www.saecollege.de/reference_material/index.html BTW Please do not start a new thread for every idea you have - you already have a thread. cheers john
