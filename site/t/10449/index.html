This is my thought for the control room treatments. I have hardwood floors and 9' ceilings. The wall construction is double drywall with green glue on RC channels. As is the room really contains sound well but as you can imagine the slap echo is crazy, so I was shooting for keeping it a more live room by using panel absorbers (ala SAE) and slat resonators to break up the parallel walls and tame the Bass while still keeping it live. any feedback would be greatly appreciated as always.
