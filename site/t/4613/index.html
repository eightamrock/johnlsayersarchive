Here's a couple links... http://equitech.com/ http://furmansound.com/pro/blncd/index.htm Basically put, balanced power is set up in the following config... Normal power uses Hot, Neutral, Ground. With 120v (or 110v) on Hot. When balanced power is used, it has 60v on hot, and has -60v on Neutral (out of phase w/ the hot side). That's the extreme basic. Now in order to achieve this, you need toroidal transformers in line. Here's another link: http://www.toroid.com/standard_transfor ... ormers.htm Hope this helps. :D
