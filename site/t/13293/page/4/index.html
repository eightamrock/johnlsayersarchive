jbassino23 November 2009#86
Guys, Lets say I'm not convinced with the sound of this room (i just recorded drums for an album this weekend there) and I want to make it more "alive" Any ideas? obviosly, taking the cloth walls apart and puting "something" instead. Wood? Drywall? We measured with a certified acoustician the noise and it was practically zero, none, nada so I dont care for any 3rd leaf effect in some places if we decide to replace cloth for hard surfaces There isnt much absorption overall on this room so i was impressed that it came out more dead than i expected, i guess the only cloth wall is eating up all the reflections. Any words of wisdom?
