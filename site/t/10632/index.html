rod gervais21 May 2008#4
djanogil wrote:
On John's construction pages, I've seen studios with wood framing covered with plaster boards , and others covered with fabric all over, which would act as absorbant surfaces.
John uses designs that utilize "inside out" inner wall construction - thus the entire wall become available for room treatment behind the fabric. I never saw this used before I "met" John - and consider this to be a proprietary system designed by him - thus you will not see it in my book - nor do I design using that system. All of my designs would have wood frames with plasterboard covering the walls inside the rooms.
My question was if you go with the former, do you add absorbant panels and bass traps on top of the plaster boards?
Yes you would treat the room in that manner.
My understanding of this is that you build the room first like any room, with concrete blocks for instance, and then build the inside room with frames that create the shape (unparallel walls) of the studio with the mineral wool inside. Is that correct?
That pretty much sums it up. I hope that helped. Rod
