Hi Wayne, I am not an expert (yet), but I can tell you that much, that tuning a HR is not a trivial task at all! It yields so many unpredictable results, that it only makes sense for very experienced studio builders, if anything. But you can generally smooth out the modes with simple porous absorbers. If you don't want to make the build a yearlong endeavor, I would recommend simple panel traps and super chunks in corners. On the results you can decide, if you need to achieve more. For more detailed answers (from me or the more experienced folks) you would need to provide quite a lot more information. Please read the stickies.
