Hi everyone, so far i read a lot of informative things at this side. I am also reading Rob's book and read some others. So I hope i could avoid the at least some mistakes. Attached you see screenshots of the current layout (autocad). I’m not familiarly with sketchup so far. - LOCATION: Austria, Europe, rental room in a old office building with several rehearsal rooms - AIM: Building a nice control / mixing room for use as my private "project studio" - USE: tracking / overdubbing (drums, guitars, vocals…) and mixing; mainly heavy bands (rock / metal) - OUTGOING NOIS: is not a problem (being in an building with several rehearsal rooms and no near neighbours) - INCOMING NOIS: more separation from live room would be good. - BUDGET: about 1000€ (1300USD) for material (could be raised if necessary) building it by my own. - EXISTING WALLS: made of concrete (about 22cm) and can not be changed , they are slightly splayed - EXISTING FLOOR: earth / concrete / wood stabs with isolation in between / covert with 2 Layers 19mm chip board + a very short industrial carpet. I don’t want to take out the existing floor if not really necessary. - EXISTING CELLING: plasterboard - EXISTING WINDOWS: are old and cover big parts of the front. - EXISTING DOORS: main door: metal fire protection door After looking thru different room ratio charts i think my ideal dimensions would be about 2,40m x 3,6m 5,0m (my room being 2,40m x 3,7m x 5,6m) My Idea is, to build a gypsum wall in front of the existing windows, so I get better room ratios and will not have a window front. This would give me storage room and the possibility to soffit mount my speakers. I would like to place transparent blocks in this new wall to get some sunlight and a simple door to get access to the storage and the existing windows. Questions: - Is my basic idea ok or are there weak points I should change? - Is it a problem, if the distance between concrete wall and gypsum wall (the gap) is not the same at each side wall? Thank you very much best regards perry
