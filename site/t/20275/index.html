Engineered stone/brick veneer for exterior leaf mass?

Started by RyanC on 30 November 2015. 0 replies.

Originally posted at johnlsayers.com, topic 20275.

RyanC30 November 2015#1
Do any of the various engineered/cultured stone or brick veneers work well to achieve exterior wall mass? I see some products listed as ~15lbs psf but it seems that some of them might have cavities or gaps etc. I'm assuming that would ruin any potential gain in TL of using this as mass in an exterior leaf. But what about the ones that are more 'brick look' where there is a grout/mortar between the concrete tiles? It would seem that with double densglass type sheathing and basically gluing a few inches of concrete to that it would be possible to achieve ~20lbs psf.
