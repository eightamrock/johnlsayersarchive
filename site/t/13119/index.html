Hello everyone. I would like to start off by telling you that I am not musically inclined at all. I work for a housing authority that hosts an after school program. Apparently they are having some kind of music class this summer and I am tasked with building an isolation booth. This class is set to begin in 13 days. The structure will have to be able to be broken down and moved and then set back up with ease because the booth will be located in a room used for GED classes when it’s available.
