Guy - the only program that I know that is Mac is sketchup.com which has a mac and pc version but it's also a 3D program - it's very easy to use and you soon get hooked on it - it will do straight 2D drawings as well. A friend recently had smartdraw operating perfectly well on a mac using virtual PC. cheers john

John Sayers22 March 2005#4
a couple of days. The main thing with sketchup is to make groups of everything - so if you want a stud create one then group it - all you need do then is double click it and you can edit it if necessary. if you don't group things you can get into an awful mess. also start to assign shortcuts from the start as they make everything simpler and faster - it's in the preferences. soon it will start to drive you crazy when you find yourself trying to orbit around pics on the net :) cheers john
