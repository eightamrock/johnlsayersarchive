If I didn't have the budget for concrete walls/ceiling anyway, why spend the extra on a slab floor?
Because it's about the best possible floor for a studio, from all points of view: isolation (unbeatable), acoustics (great), doesn't rattle, doesn't squeak, doesn't move, doesn't resonate, relatively inexpensive, tough, wears well, can be used as-is, or as the base layer for a more aesthetic finish (ceramic tiles, laminate flooring, linoleum, etc.), low maintenance, can have conduit embedded in it, etc, etc. It's hard to think of a better floor for a studio. - Stuart -
