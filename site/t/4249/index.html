Hi all! I've seen a comment about concave surfaces. The only way to avoid the focusing effect is to apply diffusers. They eliminate efficiently the hot spots. You can use absorbers but you're taking off acoustic energy that could be very useful. So I suggest to use Diffusers. If it is too expensive, install 50% of diffusers, not less. I'm designing a worship as a concert hall now and the ceiling is a dome. So I had to model it in a software, and there you see the de-focusing effect of the diffusers. Bye!!
