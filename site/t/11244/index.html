Sliding glass doors ???

Started by Soundman2020 on 22 September 2008. 4 replies.

Originally posted at johnlsayers.com, topic 11244.

Soundman202022 September 2008#1
I've seen sliding glass doors on many plans here, separating rooms, and I'm planning to use them myself on my build, but I can't seem to find any specs on them. Are they just ordinary, run-of-the-mill sliding glass doors, the kind you buy in Home Depot? Or are they something special? How thick should the glass be, and should I get the type that has "double-pane" glass (called "thermopanel" here in Chile), or would it be better to go with one really thick pane of glass in each door? I'm concerned that the relatively thin glass in "thermopanels" might end up "ringing" and resonating at some specific frequencies, so I'm thinking that it might be better to use one thick sheet of glass in each door, as thick as possible. What about the door frame: Wood? Aluminium? Plastic? And finally, how do you seal the air gaps? If it slides, then I don't see how it can be 100% hermetic, as there has to be some slight gap to allow it to slide. How do you deal with that? Is it important? If someone could post more info on the best sliding glass doors to use, or even on the actual doors you used in your own studio and how they worked out, I'd really appreciate it! Installation tips, and pitfalls to avoid, would be very useful too!
Earshot23 September 2008#2
Hi there, Im not really an expert but I looked down this track a bit for my own project before opting for a conventional double door with glass in each. Ideally it would pay to use a single sheet of glass in each sliding door. This in theory would avoid creating a 4 leaf system that you would when using 2 double glazed units. The glass thickness would depend on the isolation you are trying to achieve and it is generally recommended that each sheet of glass varies in thickness (by 1/4inch from memory) so that the resonant freq of each sheet will vary. As with all sound isolating assemblies, an airtight seal is important. Im not sure how this is best achieved with sliding doors. Due to the large area of glass req I think this option would be very expensive, but would provide a really good viewing area, not sure if this ramble helps at all, Cheers, Matt
