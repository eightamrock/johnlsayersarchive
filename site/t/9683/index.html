rod gervais31 October 2007#2
typically after - but WOW - a 4" conduit - if it's easier before - and you can protect them for the pull - you could do it before. REod
poorrichandy5 November 2007#3
The only concern with doing that will be the ends. You just want to make sure and never put any stress on the connectors. You might want to tape a pull string on the the actual cable all bundled together and pull on the pull string. That way you make sure you never pull anything by the connector. It doesn't take a whole lot of strength to pull the end off of Cat5 and I'm sure it can't be healthy on mic plugs either. Good luck!
