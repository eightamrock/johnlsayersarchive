Each court ( of which there are 3 - see drawings ) is built within a solid brick shell. ie: each court has a double ( cavity ) brick wall surrounding its perimiter. As the centre court shares walls with the 2 outer courts, it also means that that wall on either side is considered " double brick " from either side ie: there are 2 rows of bricks with an inch cavity dividing each court. These brick walls go ALL the way to the ground ( except for a small opening that was intended for ventelation breeze to go straight through to avoid moisture build up - kind of like a man hole. I will address this by filling it with layered insulation ( Super-Chunk style ) stuffed in a plastic bag. Just to conclude - the full black thick lines on the drawings = double brick cavity wall. This means that these walls have brick piers on the insides where the bearers lie upon which the floor joists lie, upon which the floor boards are fixed.
