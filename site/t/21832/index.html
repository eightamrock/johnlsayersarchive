Use my calculator to see how your performance will change. Gregwor & audiomutt’s MSM Transmission Loss Calculator Version 2.02 Thread
2. Im planing both leafs to be decoupled but my acoustic window will sit on top of these two walls... Will this couple the walls again? Is there any point or gain in decouple walls if I plan to install the window this way?
First off, it this was your ONLY option, you'd have to have a very very thick window in order to match the mass of both leaves combined. Secondly, yes, this will be the flanking point of your walls and severely compromise the MSM system.
3. Is there a way to decouple the window? is this recommendable? could you point to a resource where I can learn more about this?
Yes, put one window in each leaf. Here's a thread with pictures to show how it's accomplished: viewtopic.php?f=2&t=21396&p=144643&hilit=BRAUS#p144643 Greg
