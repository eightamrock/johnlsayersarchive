I then picked up on an idea I saw elsewhere here and added a single inside window (essentially turning the exterior windows into 'studio windows'. dymaxian18 July 2004#7
I'd hesitate to put windows anywhere on the rear wall. They will be the sonic equivalent of mirrors. If you do install them back there, set the "inner" mirrors at an angle so that they do not aim sound from the monitors into the mix position- perhaps point them sideways and install heavy absorbers into the side-walls in the right spots. Otherwise there's probably no real problem. If you can set the windows to be symmetrical about the control room, it'd be even better- and only the inner window (CR side) have to be symmetrical. The outer windows can be wherever they work best. Good luck!
