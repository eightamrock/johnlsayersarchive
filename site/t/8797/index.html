i am going to be running a pvc pipe between my tracking room and control room to be able to mount a wall plate in each room for the i/o that i require. In the tracking room, im going to be putting multiple xlr inputs and also 1/4" inputs and in the control there will be the outputs.
This is typically what is done. You'll have a conduit or chase from each tracking room directly to the control room. Multipair cable run from each room to the control room. Panels in the tracking rooms and cables going from the plates to either a patchbay or directly to the console, depending on how you've chosen to set it up.
