You could do it with 3 KVMs and suitible vidio splitting (assuming both computers use the same vid connectors). This would allow any video output to go to any monitors input. To do it properly; you would need 3 splitters that could split 3 ways and 3 KVMs with at least 3 inputs each. This could be expensive. Very expensive. Thats my best idea...
