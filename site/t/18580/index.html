Hi Fabiana, welcome. Please read the forum rules for posting (click here). You seem to be missing a couple of things! :) But what you need to do is to first analyze your room, using the REW acoustic analysis software, which you can download for free here: http://www.hometheatershack.com/roomeq/ There are instructions in the manual on how to use it. When the test is done, post the data file created by REW so that we can download it and see what the problems are with your room, and suggest what you can do to fix it. It would also be very useful to have some photos of the room, we can see what it looks like, and how it is arranged. - Stuart -
