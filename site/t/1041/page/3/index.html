knightfly15 January 2004#56
That type construction can be done, but you need heavier framing for any serious spans. Some examples - 24" centers, 2x4 #2 and better douglas fir, max span around 7 feet. 2x6 ups the span to about 10-1/2 feet, and 2x8 increases it to about 13'6" maximum - these are only for single layer of wallboard, so spans would be less for any isolation construction. Even with supporting the ceiling framing on walls, you still need to use RC to hang the ceiling wallboard, in order to isolate it from the walls... Steve
