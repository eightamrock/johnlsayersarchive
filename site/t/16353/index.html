Hi, here you can see some photos of my studio. Webpage is in development. http://www.coldgroundstudio.de/rooms.html Before I start building I want to get some input from the experts. There are no parallel walls. Superchunks in 3 corners, slot absorber (100-150Hz design center frequ.) in the forth corner (where the drum set is placed during rehearsal). Four 100 mm think broadband absorbers on the east wall and 2 on the ceiling. I want to add 1D QRD - diffussors on the naked northwall and diffusors between the broadband absorbers. In front of the broadband absorbers I want to add removeabel binary array diffussors to raise the decay time because the room is a little bit too dry now after adding all te equipment. Especially for drums. But is ok for guitar and vocals. So want to make the acoustic variable by covering the broadbandabsorbers and add diffussion in one step. See photos. I sketched the new absorbers with photoshop. What do you think about this? Thomas
