I have 4 sheets of foam insulation (4'x8'x1.5") Would this be any good for soundabsorbtion panels or sound deadening panels? I've read the DIY post on how to use 703 with a wood frame and fabric, but would the dense insulation be as useful? Thanks.
Soundman202025 November 2008#2
Depends on the type of foam! If it is closed-cell foam, then it has practically no effect at all acoustically. If it is open cell, then it might be useful. If it is specifically meant to be acoustic foam, then it will be useful, if you use it as the manufacturer intended.
