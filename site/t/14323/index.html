(AIM) RECORDING SET-UP Based around PC Cubase 5, Mackie Onyx 1640 + Firewire, Event Tr5 MAIN FEATURES Control room, with vocal booth. DESCRIPTION OF SPACE My cellar 4,6 x 4,7 x 2,10 room.
