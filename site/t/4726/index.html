knightfly1 December 2005#9
Borut, do you have any other rooms that are NOT so close to being a cube? Because there is no way you're going to get "mastering" quality acoustics in that room without moving some walls. Preferably a larger room if one is available; 3 meter ceilings are better than some lower ones, but you should have more difference between the height and each other dimension if possible. On the SAE site that was linked, there is a reverb calculator that might help you get closer to an answer - http://www.saecollege.de/reference_mate ... m#verbcalc Keep in mind that live/recording rooms and rooms for classical music need to be a bit more reverberant than control rooms, mastering/listening rooms - you should probably be looking at around .25-.35 seconds RT 60 in your case, longer than that if the room is quite a bit larger... Steve
