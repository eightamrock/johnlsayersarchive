That would be fine. That's actually the best way to do it, as long as you keep it all sealed up nicely. On the other hand, if you might ever want to use that storage space as an isolation booth, then you could do it the same way the CR is done, as a complete separate leaf. You don't need to do that just for storage, but for an iso booth, that would be the way to go. - Stuart -
