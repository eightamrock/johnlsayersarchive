knightfly4 November 2005#82
There is still some material on this site that's old/superceded by newer revelations; that's probably one such thread, hopefully I will eventually get time to change it. The newest wisdom - for "beef up" operations between studs, you would be using cleats to hold all the layers in place - gluing around the perimeter of each piece may not be necessary but it's a good idea anyway. You do NOT want to glue full-face ANYWHERE in a sound proof room, except for VERY special products like Green Glue which is a Constrained Layer Damping material, and actually IMPROVES the low end isolation of a wall. As to using "Laminating screws" and glue, Neither Rod nor I recommend this - it's too easy to get the wallboard too wet, which will soften it and let the laminating screws pull through (or worse) - also, with the exception of a single framed wall with no resilient mounts on either side (DEFINITELY NOT recommended in ANY case) there is almost no reason to avoid fasteners penetrating wallboard and studs; this is because one side of the wall should have no hard contact with the other anyway, and what little flanking the fasteners cause should be absorbed by the in-wall insulation. HTH... Steve

knightfly5 November 2005#84
Pix isn't the same as "touchy-feely" - is this stuff sticky, so it will adhere to where you put it? IF so, it should work for caulking. If it's REALLY sticky, you will still need to use foam backer rod behind it so your caulk doesn't fail with building flex. As to damping, try this - cut a short, 1" piece of the stuff, peel the paper off, and throw it at the floor. If it just stays there, it's REALLY well damped; if it does one little bounce (maybe an inch of rebound) it's OK - if it bounces wildly, give it to your dumpster. If it doesn't bounce at all, then wrapping pipes with it could improve noise control quite a bit; you'll have to experiment with that, since there are too many variables any other way... Steve

knightfly6 November 2005#86
Even if the stuff stays sticky, with a 3-point adhesion any joint movement can result in the LEAST sticky joint separating - this will be the gypsum. Safest way is to use backer rod anyway; saving money here makes NO SENSE. Damping drywall panels - I believe that would help some, but have nothing more than "gut feel" on this. I would think that sticking a couple of ropes to the panels BETWEEN stud mounts would do more for damping, but again this is only "gut feel" - as long as the stuff stays put, I don't see the harm. BTW, since the stuff is sticky, maybe a better "bounce test" would be to first wrap some tissue paper around the piece and THEN throw it against the floor... Steve
