Elmar wrote:

laminate should work fine.
Elmar wrote:
Ceiling: Is it a good idea to angle the complete ceiling? (for example about 12 degrees)… Where should the lower part of the ceiling be? At the front wall or at the rear wall?
the ceiling should slope from the front rising towards the back of the room. see drawing.
Elmar wrote:
Now there’s the big question how to achieve the “true balance of the high frequencies and the low frequencies with the right amount of deadness to liveness”. Which wall should fulfil which function (which kind of absorber)? Furthermore, how should we treat the new ceiling? I don’t think that we need to build a complicated construction because, like I said, isolation is absolutely no problem so only acoustics inside the room matter. What kind of absorber should the new ceiling be?
from a treatment stand point, bass trapping is important, if you have the space for a false ceiling in the control room, you can put plasic under the cloth to keep highs in the room and put insulation or hanger overhead. corners need bass trapping, first reflection points need absorbers the back wall will be deader than the front but not completely lifeless. if you can use diffusers around the back cloth wall, it will help but you need enough space (~5-6m) so the diffusers can "diffuse" instead of merely reflect...

gullfo24 August 2007#11
i would build a bit around the window with absorbers and also plan on a cover for it to eliminate reflections from it since it looks like it will be a main reflection point. if you look at Kendale's design, the walls are designed to act as trapping space and would be cloth to reduce reflection. you could also add speakers there to make it a 5.1 room... the front wall doesn't have to be slats. the hangers can be very effective for trapping if you have the space but do take more time to properly build. so if you want to, you can stuff the insulation instead. mineral wool, 703, rigid fiber glass, etc. all similar materials - to a degree - see Bob Golds site on various materials. you're really looking for something to be sufficiently dense enough for bass trapping.
