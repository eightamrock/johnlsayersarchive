gullfo4 July 2007#35
when using sketchup - build the basic space settings and create as group, save as a "template" file. this eliminates having to redo it later :-) then for each version, just open the template file, save it as Vxxx and you're ready to go. draw everything in 2D to get the floor plan. then extrude the walls and so on. sometimes, I group the 2D layout, put it on a new layer, duplicate it, then explode it. this way I can edit the layout copy or go back to a original 2D layout. plus if you start to add framing/construction details, you still have one of the 2D layouts for your construction permits later. I think the layout you have is workable. you should now start thinking about HVAC as air will be the next important aspect... ;-)
