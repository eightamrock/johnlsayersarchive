I'm looking for a quote to do the plans. I need to keep construction under $20,000 USD if at all possible. If needed I will build in stages, but bottom line, I need plans and I need a quote for how much the plans will cost, or maybe someone just wants to help a guy out :) LOL.. Anyway.. here goes. First off, thanks for the great forum. I wish this resource was available for my last studio. I've been chatting about it in the forums, and it was successful, but it could have been so much better. I figure if it came out that well (sound wise) on luck, imagine what I could do if it was done properly. I read the requirements for the forum, I'm going with more information better than less hoping this sets you up with enough information to know if you can help me. My main customers are single/dou singer/songwriter type clients with acoustic guitars. There will be some 3-piece Rock bands, and quite a bit of voice-over for Computer Based Training, radio spots, etc.. I have more gear than should be allowed. Obviously most of this will be stored outside of the studio and brought in as needed.. I'm not sure if you need to know the gear, maybe for size options? Main console will be a Tascam DM4800, hooked to a Windows based PC. Two 24" flat screens. I use very little outboard gear. I have Event 20/20 passive monitors that I like. I also have NS10M's Mostly Neumann and Audix and Shure microphones. Crown, Hafler, Dynaco and QSC amps. Measurements in Feet. (obviously I'll provide exact dimensions if we can move forward.) - The shell of the building already exists @ approx. 31' L x 13' W x 12' H - It has a cement slab floor, the walls are drywall already. - Both floor and ceiling are unfinished - I need not worry about neighbors and such. - Entry. If you were looking down from an overhead view, building running lenghwise we'll call it east-west... there is an entrance on the south wall about 2 feet from the southwest corner. The end of the building was a 4-panel folding door that opened to allow a boat in. That end will be framed and sealed appropriately with whatever door and its placement we come up with by design. The bump-out for the bathroom is not built on the outside yet either, but it will be located in the "west" side on the south-west corner with access as appriate.
