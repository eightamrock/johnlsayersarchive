gullfo5 December 2007#3
you're going to change the configuration so something will be different - depth of the air cavity, materials, etc. but as long as you can continue the isolation bits into the recess where the trap will be installed, then impact on isolation should be less than just cutting a hole in the wall... otherwise, the trap itself would need to be part of the isolation - mass, damped, sealed, etc. what type of treatments do you need? maybe some can exist on the ceiling-wall corners, ceiling, and be able to use thinner absorbers on the walls.

bpape6 December 2007#5
Your isolation will be impacted if you don't double up the drywall on the other side. You simply need the mass that you're cutting away. The D1's can be recessed in the same way with the same caveat though I'd leave a bit more space around them so the sides of the recess don't act as additional wells and things can scatter properly. This is going to be the same with any diffusor. Bryan
