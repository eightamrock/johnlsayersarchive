orangenumerik16 March 2008#4
Slats depth , slot width, slat width and box depth are all calculated variables that affect the center frequency of a given trap. The thinner the slats the higher the "tuned" frequency is. If you're targeting the low mid where these traps usually work best, it would become difficult to achieve that with 1/8 thick slats. As an example it should look like this for a center freq say of 258hz Slat depth 1/8in Slot width 1/2in Slat width 60in That is 5 feet ! Box depth 4in Of course this calculation is not for a corner trap wich would have a wider Q but it give you an idea. Better to get something at least 5/8in thick IMHO. regards
