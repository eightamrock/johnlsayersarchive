dymaxian4 October 2004#2
Greetings and welcome! If you're after a big facility, the best way to do it would be to go in stages, so yes- it's possible. I'll be doing the same thing around this time next year. All you need to do is determine what parts you'll need first. If you have a master-plan for the overall construction, just build the outer shell as if everything inside is going to be built all at once. Parts of the building may stand empty for a while, but better that than having to tear stuff up every year or so to add on, right? Besides, for a recording studio the outer shell is the cheap and easy part. It's the inside that you'll be spending all the time and money on. Studio design and construction lends itself to this sort of plan, anyway- if you'll be building rooms that are structurally isolated from each other anyway (double walls and separate ceiling joists, etc) then it doesn't matter if you build them one room at a time- in fact, you'll end up doing that anyway- so what if it's a year between addition of each room? Start off with the control room, then add tracking, then iso, then you can take your time on the lounge. Anyway, Giles is the resident guru of designs. If there's a laundry-list of them anywhere, he'll point it out to you.
