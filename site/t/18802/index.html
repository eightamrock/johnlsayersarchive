SU component to help with room design

Started by gullfo on 20 February 2014. 2 replies.

Originally posted at johnlsayers.com, topic 18802.

gullfo20 February 2014#1
here's a component i used to help define the proper spacing of walls and air gaps when laying out rooms. overall it helps assert discipline into the design process because you're accommodating the gaps, frame and drywall depths etc which often times gets overlooked when doing room layouts. currently this component is only for rectangular room with either existing boundaries (inner room only mode) or the need to build external walls. you can overlap these components to get the layout then explode and erase extraneous lines. sometime later this month i'm going to update to include angled rooms and positioning of exterior walls and interior walls so it's possible to mix and match (e.g. a room needs an exterior wall added to a basement but the rest of the rooms are based off the existing block walls).
