mpedrummer14 September 2006#2
So, the experts will be along in a second, but to my understanding, you probably don't want to use glass block, depending where you're putting it. Basically, glass block is hollow, which creates a desireable M-A-M (mass air mass) system. However, if you put another pane of glass in front (your existing window) you're creating the dreaded three-leaf system. Use the search feature to look for John's explanation, I'll never be able to do it justice. So, assuming I'm understanding what you intend to do, you want to avoid using the glass block altogether. MPEDrummer
