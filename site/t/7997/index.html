kendale20 January 2007#2
Aloha, Here's the info I was given:
when you've completed a drawing go to window/model info/statistics. Here is where you can purge the whole drawing. It removes any components that' you may have tried but aren't in the final drawing, similarly with materials and layers that aren't used. I've set the upload limit at 500k. if it's a bit over zip it. - John Sayers
If it's still too big and you don't have a zip program, try posting a 2D graphic: - click on "file" tab at top of page - scroll down pull down menu to "export" - scroll over to 2D - assign where you want to file to go (and where you can find it again!) - use an imaging software to crop off blank space" and resize to 700 pixels wide - then add as attachment to your post Hope this helps, Aloha 8)
