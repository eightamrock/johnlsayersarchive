yarrick197 January 2012#1
The location for my studio build has HVAC ducting that supplies heat to the rest of the house. My plan is to seal off all the vents in the studio area so the sound doesn't travel through the duct work to the rest of the house. I figured I could use in wall electric heaters as a heat source. Does anyone have any suggestions for a good electric heater to use? Thanks, Paul
Soundman20207 January 2012#2
My suggestion would be to NOT seal of the HVAC, and use it correctly! Install silencers and follow the usual practices for isolating the ducts. You cannot seal of the HVAC: That would be dangerous. If you isolate the room correctly, it will have not one but two complete airtight seals around it: How do you plan to breath in there, with no HVAC? :shock: :) - Stuart -

yarrick1928 January 2012#5
Thanks for the feedback. I've reconsidered sealing off the vents. I've attached a few different options I have to tap into the existing HVAC system. In both images the striped ducting are the returns while the solid gray is the heating/cooling trunk. First Option: Air Return - Add two separate branches to the existing air return ducting. Heat/AC - Branch off the existing heating duct. In the control room, run the ducting up in the floor joists and add a vent over by the window. In the live room run a short duct with a vent just a few feet into the room. Second Option: Air Return - Add a single branch from the existing air return ducting and then run that branch up through the joist into the control room. Heat/AC - Same as above The advantage to the second option is that I wouldn't have to build a second soffit in the basement portion of the house creating a "cleaner" look. On the other hand, doing this creates more separation between the return units from the control room and live room. My biggest concern is sound traveling through the duct work between rooms (including the rest of the house) and wrecking the isolation. Whats the best way to prevent this?
