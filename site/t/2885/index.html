I am in situation where I need to start planning studio made of logwood. This is own building with space for other needs as well, but this time we can think acoustics before making the building. What shape is best for control room and how large should it be to service well acoustically. It should be surround (5.1) compatible. one window should be between main speakers and during sound for picture, window is going to be covered with screen. dont really think other windows needed in this space. I have no plan to record acoustic instruments, its more like post production studio and hometheater same time. Is diamond or shell like form best? ideas and links to well done studios are welcome. as a note we dont plan to make 90 degree angles in this room if not needed. Studio is going to be in one end of building and other rooms behind this space and perhaps at 2nd floor. Or perhaps studio is going to be located at 2nd floor if better that way. Design should be done so that additional basstrap need is little as possible. I also want to keep pure wood surface visible if possible. hello john, its solid pine. this pic is just example building currently under construction. it can be as large as 16" (size of wood in storage) and optimal lenght for one wall is 4 meters. After 4 meters there is good to be angle but not necessary. angles can be from 10 degrees and up but its preferrable to have 2 or 3 angles at maximum (like 30 degrees, 45 degrees and 90 degrees). as you see these are not round log, but cutted. material that comes from this cutting procedure can be used for panel surface purposes just like there on 2nd floor in picture. Current plan is to start sculpturing the base building next winter and its going to be guesthouse, car garage/workspace and other needs as well but large partion is for post production / project studio (that works as hometheater as well) with voiceover/foley booth. jukka
