gullfo8 October 2007#7
i think my first recommendation is to get a copy of Rod Gervais's book Home Studio Construcion - Build It Like the Pros. it has numerous details on isolation and proper construction techniques. some thoughts - if this is operated as a commerical studio, it will likely need ADA compliance. if so, things like homedepot style sliders won't work because you'll need to have them flush mount and the slide gaps very close - hence a commercial door makes sense. Rod has some information posted in the construction forum with some brand information as well. as far as sketchup, it takes time to learn but you can use the push-pull tool for many shifts in walls and such. i recommend creating the base garage as a template (group everything) and using this to create versions from. this way if you goof up you can re-open the template and restart. on the ceiling, if you have the option for 12 degree slope thats good, but you could get away wih using clouds overhead. less construction and just as likely to meet your needs.
