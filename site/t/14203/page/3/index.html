gullfo13 December 2010#53
i'd shoot for something in the QRD prime=13 or if a primitive root sequence, something like prime=17. you could built them without well dividers out of 2x lumber or heavy foam on a plywood backing panel. if you wanted to go up a bit in complexity to 1x lumber (or equiv foam), then i'd go with a QRD p=23 and PRS p=31. if you build them with the well dividers, use 1/8" ply.
