a quicky 3D template you can size for a given room and it let's you view the mode spacing and main frequency on a given axis. due to the way the nesting of components works in SU dynamic components, it may run for a while (each time you adjust something). one option is to set it "No" for "showing 3D", size it for the floor (x-y axis) using the scale tool, then set it to 3D and size it vertically (z-axis). cheers! use this link from the 3D warehouse as the file is about 1.8MB. http://sketchup.google.com/3dwarehouse/ ... 9309166000 attached is a simple help file.

(i updated it to use a group so it's faster and smaller now). i may ultimately have to re-do this as a Ruby script to make it more compact but that will have to wait until i have time. here's an SU file which has the component in it. you might have to enable dynamic components in the tools settings. (sorry for the size - i zipped it as it's 625Kb) note: i downloaded it from the 3D WH and dragged it onto a blank SU file and it worked (have to answer the delay dialog). also, if you do not see the dynamic component options in the context, use the view -> toolbars to view the dynamic component toolbar. i found a bug in SU 8 which sometimes prevents the context menu from displaying and reported it.
