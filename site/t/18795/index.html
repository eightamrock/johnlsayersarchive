Related question - any tips on best practices for getting file sizes smaller?
For SketchUp, on the "Model Info" window select "Statistics", then hit "purge unused", and wait a few seconds... SketchUp keeps all your old geometry internally in the file when you delete things, and only dumps it when you "purge", so files can get big if you never purge them. In general, if you try to upload any file to the forum (skp, jpg, mdat or whatever) and you get a message saying it is too large, then it is OK to use a file sharing service such as Dropbox, and then just post the link in your thread.
