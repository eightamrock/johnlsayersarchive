gullfo5 December 2007#30
close enough is usually good enough - especially if there little or nothing you can do about it... so if more space is better for you, then go with more space and if the mode difference isn't great then just use other treatments. the only time this doesn't work well is if you create a room where the treatments would occupy as much (or more) space as doing the other way...
