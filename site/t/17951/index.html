Soundman20206 November 2012#2
Hi "SIROPIP", and welcome! :)
...how is a structure like this kept rigid if it is in effect a freestanding structure?
How is a normal house frame kept rigid, if it is in effect a freestanding structure? :) You don't need skyhooks hanging from the moon to hold up a house frame... Neither do you need anything additional to hold up the "inner" room of a fully isolated room-in-a-room studio. The inner framing is self supporting since it is built in the same way as a normal house frame. The four walls hold each other up, and the ceiling frame completes the structure, by bracing the walls across the top If you are concerned about sheer forces, then replacing the first layer of drywall with plywood or OSB will provide more than enough sheer strength. The problem is how you do it if there is no ceiling framing, such as for example if the ceiling is to be hung on RC from existing overhead joists. There are solutions for that situation too. But for the normal situation of four new walls plus a new ceiling, the framing itself is self-supporting, if built correctly. - Stuart - PS: It ain't a stupid question at all! The only stupid question is the one you DIDN'T ask... ! :)

xSpace7 November 2012#4
" if the studwork structure must not touch the existing walls in order to create an air gap then how is a structure like this kept rigid if it is in effect a freestanding structure?." It depends on the isolation you are attempting. A "let in" diagonal brace at all corners will provide shear support for exterior walls and will also do the same for interior wall assemblies. The OSB suggested does the same in respect to shear (under minimal load)/ adds mass/ but if you have a specific TL target in mind, then you have to know that there are options.
Soundman20207 November 2012#5
Can i brace the walls as I go?
You sure can! Temporary bracing is a smart idea, and you can attach it to anything that will do the job safely. Just don't forget to take out the temporary bracing after you are done! :) - Stuart -
xSpace8 November 2012#6
Bracing an assembly is part of the project, part of any project part of any thing you do with vertical wall assemblies. It isn't something that you will think about as you are doing it, it is a requirement to keep a plumb square environment. It isn't like you can omit this step and everything works out,it is part of the process.
