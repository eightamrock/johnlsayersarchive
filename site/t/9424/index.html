Hi all, I've been using a spare bedroom as a micro post mixing room and using the closet as a VO booth. Right now I have some recycled auralex I scraped off the walls of a defunct studio and have 4'x4' on the left early reflection point and have it wrapped in the front corners so it covers the corners and continues behind the monitors. (Hopefully the pix make more sense). For now, I have attempted to mock up the room using sketchup. The actual dimensions for the main room are 11.5'W x 11.5'L x 8'H. (The window is on the South wall, I mix facing East.) The closet is 5'2" (South and North wall) x 4'11" (West wall) x 8' high. The doors should be visible on the model. For some dang reason sketchup would not let me manually input correct sizes for some of the walls. :x The floor in the main room is oak parque and the closet has concrete covered with carpet. My main plan is just to go for absorption at this point by making some traps. I've got the two front corners, east, west and north walls available. I can get 2" 703/705 from SPI locally, and they offer FRK. I'd like to make as many 48"x48"x4" traps as possible for the walls, but should I only use the FRK on the corners with the paper facing outward? Should I make the W wall covered lengthwise, or will I be ok if just a 4'x4' area behind me is covered? As for the booth, I'm going to attempt 4" from floor to ceiling on the N and S walls. How about the FRK here? On the W wall I have a monitor mounted from a swing arm for the actor so I'll have to split up the dimensions of the traps. Also, can the old auralex be used in the trap design? I thought I read somewhere that putting them behind the traps may help. Thanks in advance for anyone bothering to read this. I hope I added enough info and followed the posting guidelines. :) It's late and trying to learn sketchup has melted my brain.
