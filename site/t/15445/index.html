MTLA wrote:
Currently I have only added single layer finishes and am ready to add the second layer of drywall however want to know where to put screws or how to attach it with the least amount of coupling. Thanks!
That shouldn't even be a concern (least amount of coupling). You want your hard panels to be connected securely to a secure framing member. Now there are some things that the installer should have already been prepared for. E.G., the screw pattern for the base layer is usually a shorter screw with a minimum pattern where as the second layer will require a longer screw at a predetermined pattern to keep the installer from hitting the already existing screws but that will bind the panel(s) securely with the recommended pattern. This is true for either side of the wall, doesn't matter if it is interior or the exterior side. The reasons gluing is not recommended is two-fold. The first is that the coupling of the two masses does not create one dense panel with an increased ability to isolate sound across the frequency range, and secondly but most importantly, gluing doe not create a secure installation and will always be an accident waiting to happen.
