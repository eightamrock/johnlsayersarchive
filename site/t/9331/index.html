kendale31 August 2007#5
Aloha, You have a very nice space to work with, and a good basic layout. However, here are a few observations on the proposed control room/vocal booth layout: - room ratios less than ideal - resulting modal response questionable - absence of line of sight to the vocal booth - doorway in front left bass trap/soffit of control room - doorway in rear right bass trap of control room - piano booth may be a bit small for some types of recording genres Hope this helps, Aloha 8)

medboyle3 September 2007#19
quickest way to make the file smaller is to do Click Edit>Select All>make group then Copy, open a new blank sketch up and paste Just save the new sketch up and this should make the file small enough to post cheers lan
gullfo3 September 2007#20
also in the menus "windows -> model info -> statistics -> purge unused" will clear items (objects, components, materials, etc) not in use. copying from one file to the other acheives the same effect... using as few materials and graphic objects as possible will help. also, after generating a graphic remove the non essential bits like drum kits, keyboards, mixers, etc. that have a high/complex poly count and purge the file. this way you eliminate things not needed in the sketchup file (for discussion purposes...)
