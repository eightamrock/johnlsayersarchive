sandledfoot9 March 2007#4
anoy.... sorry, i don't know how to respond with anything usefull about the acoustics, i'm just about the same phase, and planning my own room, so currently i can comment... but not sure if it's good advice or not! not sure if you need so much bass trapping in the iso booth... however, it looks like the size of your traps in there may act as broadband absorption, which would be great anyways... would be great... (although, as Ethan points out, youcan't have too much bass trapping!) oh... and the cloud in the iso booth? is it going to have a firm surface, or just absorptive? i'm thinking the iso booth should be as dead as possible for you right? in which you would eliminate all reflective surfaces... as for the rest, it looks like your on the right track... don't forget that you can use the horizontal corners too (floor-wall, wall-ceiling), which might help in your situation, since some of the vertical corners are doorways... this can also help keep some traps out of the way (and free up some floor space). i'm just reading thru~! nice build though, looks great so far... ! good luck and keep posting some pictures! cheers! k btw... my forum build has almost 6600 views...and a halfdozen replies :roll:
