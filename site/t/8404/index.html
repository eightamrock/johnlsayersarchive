gullfo18 March 2007#7
if you need isolation - use 2 walls instead of staggering the studs. isolation on a pair of 2x4 walls versus 2x4 on a 2x6 or 2x8 plate will be much higher. so you're talking about 3 1/2" versus 2" to achieve probably 6-10db more isolation (50-100% more). not sure if you have the option to disassemble the existing walls and re-arrange things or not. Kendale's last design looks good. keep the longer CR if you can.
