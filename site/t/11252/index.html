Greeting to all Location - Currently a I have a CR, booth and studio as below located in Perth, Western Australia. Current situation - External walls are double brick. Ceiling height is about 3.5meters which is a suspended ceiling from a gyprock ceiling above that and a roof voide above that. Priorities - First making the control room sound better and Second making more use of the space available. The booth is just not used enough and I think the space would be better making the CR larger. Plan - What I'd like to do is knock down the wall to the booth to make one larger Control Room to make it more useful, and hopefully sound a bit better. Options - There is a double glazed window between Control Room and Studio - would it be feasable to use the glass from the Booth Wall which will be removed to extend the width of the remaining window? (assuming the glass is the same thickness - hard to tell without partially dismantling) What I'd like to do is soffit mount the monitor speakers pointing longways into the room which would give around 10-11 feet of space behind the mix position. How does this sound? Has anyone done something similar to an existing facility? Any experiences I'm guessing the expensive part is going to be the window - making it wider. If it's possible to re-use the glass from the demolished wall that would presumably save a bit, otherwise it's going to be two expensive new panes. Budget - about 10,000 dollars Thanks
