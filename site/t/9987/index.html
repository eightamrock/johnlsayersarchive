gullfo7 January 2008#3
for a start - create a good and accurate 2D floor plan make it a group. save it as your base template. create new version from the template. label each new version so its easy to keep track. its not unusual to have 100 versions when you're doing it yourself... then add simple boxes or simple shapes based on equipment dimensions. (use lots of groups or component-tize objects). save components of your boxes to your disk so you can re-use them in new versions of the design. this allows you to rapidly build new version as you get ideas and to place things without a lot of overhead and upload the sketchup to here (if desired) without having a large file size. keep materials to a minimum. use tools -> stats -> purge unused often to keep things neat. 8)
