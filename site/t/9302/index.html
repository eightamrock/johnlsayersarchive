Hi, everybody. Long time reader, sparse poster. I'm very, very hesitant to post anything because I've always been able to find my answer by searching the forum, about which I am INCREDIBLY GRATEFUL for those that came before to ask and those who answered. :) However I haven't been able to find an answer to this concern. I'm putting together a small combination studio/control room (you'll see more on this soon), and I want to put independent slot resonators on the side walls so I can move them if I need to. My question arises from the fact that where some of these resonators are going to be, there are also going to be surface-mounted electrical, phone and cable outlets. It seems that my three choices are: a) Move the outlets to where there are going to be no treatments that butt against the wall b) Build the resonators directly to the wall, negating the need for a back panel. This will put the outlets in the resonators. c) Offset the independent resonators about 4-5" from the wall, leaving room for the surface-mount outlets. Firstly, I like having plenty of outlets, so I don't think that I'd get nearly as many as I'd like by putting them where no treatments are necessary. This is a small room, so will need a good deal of treatment. I wouldn't mind building the resonators directly to the wall, except for the fact that 1) I wouldn't be able to move them if I wanted to and 2) I won't be able to mount them at some critical points, because I have windows on one sidewall and I believe this would be against building code. So ultimately, if I could, I'd like to just leave a space between the back of my resonators and the outlets. But I have a few concerns with this. 1) Will the small space behind the resonators cause a ring? Obviously, independently housed bass traps need to be flush with the corner, but is it necessary with all fully-enclosed treatments? 2) Will this negatively effect the performance of the resonators? It seems that with the opposite absorbers closer together, they might have to be tuned to SLIGHTLY higher frequencies, but they wouldn't otherwise be effected. Here's a preliminary Sketchup file to give you an idea of my intended setup thus far. The wall studs are already up, so I can't change anything about window and door positions. The first file is an example of an offset resonator with a surface-mount electrical outlet behind it (just in case I didn't explain it well enough) and the second and third files are a couple of my attempts at the control room. Thanks! Dany

John Sayers24 August 2007#3
Dany - you must remove the existing power outlet and seal up the hole in the wall and seal the cable coming through the wall. Then extend the cable and mount the power outlet on the face of the slot resonator.
