gullfo19 November 2007#2
one of the useful tools is the house builder scripts from the Ruby Script depot. http://www.crai.archi.fr/RubyLibraryDep ... uilder.zip this set of tools (I recommend the extension scripts as well) allows you to rapidly draw up framing, roofs, etc. with the caveat that once you do that, you still have to adjust bits to get them actually correct, and it has its idiosyncrasies... the best approach to SU is to have a strategy. one that works for me (most times) is to carefully layout the floorplan of the existing space, then group and lock it. then add in a floor plan for the design, group and lock that. then you can begin to create the 3D using scripted tools or simply using the push-pull tool. complex things like multiple-angled soffits with windows and so on are hard to model no matter what.
