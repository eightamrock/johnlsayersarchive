Hey there, and welcome! That's actually a good point: As far as I know, there isn't any such thread here, but it sounds like a good idea. Most designs / SketchUp files appear in the threads of individual builders, but I don't think there is any thread that links to all of them. It looks like the only way to find them is by scanning though the build threads. But that's actually a very interesting occupation! When you do that, you run into so much fascinating information about acoustics, construction, isolation, treatment, etc. that it makes the hunt for SketchUp files worthwhile. The other issue is that most designs here are tailored to fit specific spaces, budgets and needs, so many of them might not be that useful as a "drag and drop" approach. But they'll still be useful for getting ideas. - Stuart -
