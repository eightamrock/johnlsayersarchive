carpwftx wrote:
Because I am not superior. Smile
I don't think building a double wall is any more difficult than building a staggered stud wall. The only additional materials you'd need would be the 2x4s for the top and bottom plates. You'd get better isolation (even if you're isolation needs are not that great). It also means the drumstick has to be thrown a lot harder to do as much damage! Also, since the amount of work and materials is not that much more than a staggered stud wall, if it were me, I'd go with the double wall only because of the isolation does need to be improved, I think you can get more with another layer of DW on each side of two walls than one. It's not that hard to do (I didn't have any skill at this either when I started and I would think it would be much harder to build the separate walls than one staggered. I mean, what if you get interupted half way through putting in the studs and put two on the same "side" next to each other? :-) len
