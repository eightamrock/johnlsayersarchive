Soundman202013 February 2009#12
...and the plugin corrected it
Sorry to be so blunt, but no it did not. It did not because it cannot. (marketing hype aside). It is an equalizer. A fancy one, yes, activated by an RTA, but still an equalizer. Therefore it CANNOT correct reflections, reverb, resonance, modes, and other issues that are related to the room, no matter what the sales pitch says. Unless it can suck sound back out of the room after it starts bouncing around too much (and do so selectively in both space and time, accurate to 1 Hz!!!) then there is nothing at all it can do about those issues. All it can do is disguise some of the issues superficially. It only corrects frequency-domain issues, so if the sound improved when you turned on the plugin, then most likely there where existing serious EQ issues with the rest of the system (speakers, amps, interfaces, whatever). All it did was to fix system issues, not room issues. If a cheap little EQ plugin really could do what it claims to do, do you really think smart audio people all around the world would carry on spending big bucks to build and treat studios? - Stuart -
