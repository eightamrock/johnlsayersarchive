So far I've planned for: - 16 channel snake cable for microphones and DI signals - 4 analog lines for headphones - 4 analog lines for line lelvel signals - video cable for tv camera Anything I've forgotten? Has anyone ever wished they had run midi lines between the control and live rooms? Thanks.
knightfly31 May 2005#2
MIDI lines - yes, for recording clarity (if recording a module direct) this would let you put the module in the CR, so actual audio wiring is short. MIDI lines max out at around 20 feet, so if longer you'd need some kind of THRU box to reshape the pulse train, or an expensive optical translator pair. Cat6e cables so you can control a DAW from any room in the studio - Cat5 extender setups run about $300, you can use either a laptop or just a keyboard/flat screen/mouse to run things from any place within about 500 feet - or http://www.johnlsayers.com/phpBB2/viewtopic.php?t=3190 ... Steve
