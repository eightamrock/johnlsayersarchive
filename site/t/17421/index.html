xSpace22 February 2012#3
It is a big drum head Md.poneer. I do not know what you have built this floor on, but if you had a concrete floor, you would have been better off to use that. As we know it, mass is what it takes to stop sound vibrations so when you think about this floor does it have mass? Not much...and even if you add more it will still be a drum head but the natural frequency will move down. 3/4 plywood has about the same weight as fire rated 5/8 sheetrock, so you might get an stc rated for a one side sheathed only wood framed wall/floor of about 25 stc. If you added (doubled the mass) another sheet you might gain 3dB, now you are at 28...double again (two more sheets to the already existing 2 sheets after the first doubling) and you gain...3 dB. Lot of stuff to get 31 which is a bit better than an average interior wood framed assembly with 1/2 rock on both sides. But there is still flanking. The wood wall frames sitting directly on top of the plywood essentially tie all of the walls and floor together so that any vibration that runs thru one will go directly into the other, and reduce the overall TL of the build.

You would only need that if you did not have a massive floor already: you do. Yours is concrete! Sand is not necessary. Why do you think you need to float your floor? How much isolation do you need? You ONLY need to float your floor if there is a good reason to do so, such as if you need very, very high levels of isolation. So first you need to define how many decibels of isolation you need, and if you have other issues that might imply floating.

You can, but that would add even more expense, and for no benefit! Floating a floor also means that you have less height in the room, and height is important for good acoustics.

If the floor is not level, then use self-leveling cement to fix that. Once it is level, then one good option is to install laminate flooring. It is not expensive, it is y to install, it looks very good, and is also good acoustically. (Sometimes it is called "floating floor", but that is not really a good name, as it does not "float" in the acoustic sense, so don't get confused about that!)
