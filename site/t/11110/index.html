I'm planning to build a new studio in The Netherlands, at the moment i'm looking at all the different designs on the internet and i'm making some raw sketches. The room in which i'm going to build the studio is a rectangler room with the measures of 15 x 6.75 x 2.4 m (36' x 22,14' x 7,87') In this room there are several existing doors and windows (see outside walls image). In the raw sketch image there is a sketch of the layout i've in mind at this time. The plan is to make a controlroom, liveroom, vocalbooth, a place where artists can relax/wait and there must be a place for our live equipment storage. I'm planning to do the communication between controlroom and the other rooms with big LCD TV's and camera's. This for optimal audio isolation between controlroom and liveroom. This has some disadvantages, because now you're not facing the liveroom when you're working in the controlroom, but on the otherhand the walkingdistance to the liveroom is very short, and for lazy people like me, this is perfect. :D (it's not a bug, it's a feature) :lol: Please tell me what you think of this raw sketch and please let me now how to improve or how you would plan the layout if you had the same room. This is my first studio i'm building, so every advise is more then welcome. Thanks in advance, Jeroen

It looks so easy but there are a few problems in the existing room which i have to take into account when making the design layout.
