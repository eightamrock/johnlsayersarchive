Tom, > looking for a source for test tones or a program for analyzing the room for frequencies. < Test tones show only the raw response but not time-based issues like early reflections and ringing. They're still useful though. Start here: http://www.realtraps.com/test-cd.htm And see these too: www.etfacoustic.com www.hometheatershack.com/roomeq/ --Ethan
