knightfly12 November 2006#2
One favored ratio is 1:1.6:2.33 - simplified, this would be (with a 10' ceiling) 16 x 23.3 feet. IF you wanted more floor space, just keep the same ratios - for example, multiplying all values by 1.2 would give you 12' ceilings, with inner floor size of 19.2 x just under 28 feet (27.96 to be exact) In actual practice, these old "golden" room ratios were derived painfully on paper and can be improved on somewhat - for example, the numbers I gave above actually have some modes doubled and tripled in the upper range (that we care about for modes) at around 200-300 hZ - lowering the ceiling on that room to 11 feet actually improves things. Once it's built, just the basic corner/ceiling/reflection points treated should make it pretty nice to play in. Having a rehearsal space that allows you to set up the same as you would on stage is very nice, did that myself when I was still willing to wipe others' noses, and it did a lot to tighten up the band... Steve
