Hi Hugo, are these windows double or single pane windows? If they are double they don't work!!! Don't angle them, as Steve and Rod often point out this is weakening the TL. The main reason for doing this is to have no optical reflections. Is the frame a hollow frame with several spaces for thermal isolation? I'm not sure, but if so, I think it will perform very weak. I would go for solid wood then. Florian
