Shape, it isn't a dumb question - but it would have been even smarter if you had asked it BEFORE constructing your room. When framing is done with metal frame studs (even with heavy guage) it is customary to install blocking for a backer in any areas that one might want to attach things..... that is obviously impossible if the walls are already finished. I would guess (however) that isolation is not a big issue in your room - would this be correct? I await your reply. Sincerely, Rod

Shape, Nlope - I would recommend that once you determine where you want the shelving - you put a row of 2x6 cross bracing (on the flat) all the way across at the height of the shelf top (to one bay each side of the shelf) And then add a 2nd row the same but at the bottom of the shelf brackets you are using. This way you can install your brackets anywhere you might want them (nd not be tied in to centering on studs - which usually don't layout symmetrically on a wall) & the added bracing will transfer some of the load to adjacent studs (which will go a long way when using light guage framing). You can do an easy little notch at the edges of the blocks to allow them to slide up flush with the face of the studs. Rod
