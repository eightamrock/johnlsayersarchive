Soundman202015 January 2010#6
Yeah okay, would there still be a need for the resilient channel if we went this route?
If you do what John said, and build a proper "room within a room", then no, you do not need resilient channel. The framing for the inner "room" is already decoupled from teh outer "room", so adding RC is pointless. The purpose of RC is to decouple, but the framing already decouples. So you can save money there by not using RC, provided that you take great care to ensure that the inner-leaf framing is totally decoupled from the existing walls and ceiling. - Stuart -
