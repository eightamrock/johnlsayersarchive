Soundman202011 June 2012#4
Hi Stuart, and welcome! How could I not welcome a guy with such a great name!!!! :)
I'm not sure if a room with such a short ceiling height (1800 - 2010mm) needs a cloud,
It probably will. Most rooms will need some sort of cloud on the first reflection points.
I've distributed identical 400x1200mm panels around the room based on where it seems the sound will hit first.
But you don't say what type of panel you are talking about! Absorption, diffusion, tuned membrane, reflective, perforated, slatted, etc. It would really help to know what those are... If that is all absorption, then you might have too much in there. It would probably be better to approach this using the commonly recommended method around here: first, measure the empty room acoustically using REW, then add the first round of treatment (superchunks in corners, absorption on first reflection points and the back wall) then measure again with REW to see what that accomplished, and what still needs to be done, add some more, measure some more, etc. This is a control room, so the basic constraints are easily understood, and the basic plan is pretty "standard" (if there is such a thing as "standard" for studio design!).
but I figure if I start getting the listening position right the rest will fall in place.
If done right, then yes! Start with good geometry for speakers / listening position / walls, and basic treatment, then move om from there by stages, as needed.
-The speakers will be on home built welded steel stands, possibly with some prefab pads to sit on between the speaker and the stand
Make those stands as massive and heavy as you can. Fill them with dry sand. And build them to get the speakers at the right height: the acoustic axis of the speaker should be at 1.2 m above the floor (note! Not the top or bottom of the speaker: the acoustic axis!) And yes, use a layer of Sorbothane between the stand and the speaker, to decouple it properly.
Made the panels either side the listening position angle inwards at 6 degrees
That would only be necessary if they are solid, hard, rigid reflective panels, and you are hoping to treat flutter echo with them. If they are absorptive panels, then you don't need to do that.
and then the panels behind the speakers at 60,
That's one possibility, but a better idea would be superchunks. Of course, the very best would be to soffit-mount the speakers! - Stuart -

Soundman202021 February 2013#14
polyester, 32kg for the superchunks and 48kg for the angled panel absorbers and wall panels.
That might be OK, but I'm not very up to speed on polyester, or what density it should be for optimum gas flow resistivity. The 32 kg/m3 recommendation is for fiberglass insulation, and the 4k kg/m3 recommendation is for mineral wool insulation. Polyester very likely has different properties that would imply different densities. can you get any actual independent acoustic test data from the manufacturer, that shows detailed specs on how it actually performs?
guess we'll have to just place the plastic sheeting over the appropriate panels. If not all of them?
Some, but not all. Do the ones overhead with thin plastic, for sure, and the actual corner bass traps with thick plastic), but do not put plastic on the others initially. FIRST, test the actual room response when you have done that, using REW, and see how it is behaving with just the overhead plastic. If you are losing too much of the highs, according to REW, then add some palstic to the others, one panel at a time, until you get a good balance. - Stuart -
