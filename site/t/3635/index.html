Hey guys, I'm new here. Read several topics but haven't really found out what I need. I have some experince in recording but not in studio layout and design. We are wanting to do our own recordings. I will be using Cakewalk Sonar 4 to record and master with, Alesis studio 24 sound board, Layla 3G audio card running to a Pentium P4 3.0gz,80gig hard drive,1gig ram computer. So, I'll tell you what I have and hopefully you can give me a layout that will work for me. I'm on a pretty strict budget so be easy on me. I want to build it to sound good, but as least expensive as I can get by with. The studio is going to be in my basement. It measures 30' x 50' with the entrance at one end. I would like to have 3 soundproof recording rooms. 2 for vocals and 1 for drums/vocals. And of course the Mastering/Engineer room. I need to know the dimensions and the materials needed to build this studio. Will probably have to start with the Mastering/Engineer room and drum room, and then add the other two rooms later, but need the total layout so I can plan for everthing. Can take pics of the basement if needed. Oh.........I live in the southern part of the United States....Tennessee. Thanks, Ronnie

John Sayers28 April 2005#7
Given a larger space (25 x 30) i'd lay it out in a similar way - the conrol room doesn't need to be bigger so I'd use the extra space for a larger drum room and maybe add a new booth in front of the control room with a window access. For soundproofing I'd still build a room with in a room isolation but not go to heavy isolation walls - i.e. only one layer of drywall. cheers john
