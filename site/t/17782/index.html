My question is how much can these designs/shapes be scaled up or down to fit a needed size and how would that affect their sound?
In general, scaling up should not be too much of a problem, but scaling down might, for several reasons. For example, you might end up with the ceiling too low to be usable, or make the room too small to use diffusion (assuming it was pretty big to start with).
For example I looked at John Sayers Control Room Plan 2 design that measures 4.65m x 6.1m. If that room where scaled up/down how would it affect the sound and frequency response?
It might, yes, but the question is "how much?", and the answer is "that all depends...". Scaling a room will still keep the ratios in tact, so that isn't a problem, but if you are going down in size you might end up changing the modal support and spread too much, so that the room will no longer support some of the modes that it would have, and the spread can suffer for the same reason. Also, any devices in the room that were tuned to a specific mode will now have to be re-designed, since the modes will have change to a different frequency. The relationship between the room dimensions is the same, but the actual frequencies of the modes have changed, and that could, indeed, have an effect. So if you do scale something, then be sure to post the result here, for people to look at and comment on. - Stuart -

Stuart answered great, like he always does. A note on scaling. Where a wavelegnth is involved, like full range absorbers, the dimensions of the absorber do not scale. A 10' wavelenght is still 10', regardelss of how much larger, or smaller the rest of the room is scaled. Andre
