full_bleed wrote:
How would you, or could you, calculate room modes for two rooms that are adjacent from each other but open by a passageway?
Short answer, you don't bother. Further, mode calculations are used only when designing a new room when you have the chance to build or move walls. If this is an existing room that you plan to leave as is, then a mode calculation is moot and academic at best. All you can do is treat it properly with bass traps etc.
