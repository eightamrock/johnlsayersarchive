Hey Guys... I'm getting ready to start looking for quotes for the HVAC system in our studio we plan to begin building in January. Here is the design we have planned. I know there are some experts on this forum, does anyone see any huge flaws? Attached is the design. Summary: - Remove all existing, change ducts to galvanized w/ fiberglass lining - Increase duct size - 26"x16" main, 12"x12" live room/iso booth - Stagger ducts so 2 supplies are not directly across from each other on main supply - Use flex duct for connections from damper off main supply to diffuser - Main return duct - fiberglass lined galvanized - Cut 24"x30" hole in top of main return with batt insulation on ceiling above opening - Added in a supply for back entry/hall to account for excess air in the system - Use canvas connectors to attach ducts to rooftop unit - Possibly remount the roof furnace on Isolation Pads - Each return duct will be venting into the cavity between the existing ceiling and the isolation ceiling. So, with this plan, there wouldn't be a continuous duct, it would just be room to room flow. Thank you for any views/responses!

xSpace4 January 2011#7
My rating is "Not". This design has more flaws than I can see, the main one being the connected trunk and arms to the rooms effectively building a bridge for sound to jump into one room from another room...just like a residential system would do. The other is the ducting is too small so when it reduces and increases the air speed, noise is introduced. Same goes for the returns...too small based on what I can see. Those isolation boxes you require should not be left in the hands of a carpenter unless he has built a few before and knows what it is you guys are trying to attempt with this decoupling, sound isolation item.
