Soundman202012 October 2012#9
Floors, walls and windows are already done in 3 of the rooms.
If the floors, walls and windows are already finished, then there probably isn't much we can do to help at this stage. Particularly so, considering that there are several windows marked as being both "double glazed" and "angled", so clearly your isolation is already decided. The major decisions about isolation, layout, geometry, ratio, and suchlike were doubtless taken before, so that only leaves treatment. So I guess you are asking for help with your treatment? If so, then we'd need to see how you are going to lay out each room first. Just as a matter of interest, how are your walls, floor, doors and windows built? And what level of isolation are you getting? But you also have not shown any dimensions at all, nor any information about how the rooms are responding acoustically, so we can't help you with treatment, either!
Should I board up the windows in the top room if I want it to be a mixing room?
I guess I'm a little confused: You have already done the isolation, which includes "angled double-glazed windows", so I don't understand why you'd want to board them up? It would be useful if you could provide a lot more information about what you originally planned to do here, your original calculations on isolation, how you built the isolation walls, your overall goals, your budget, etc. so that we can understand better what it is you are trying to do, and what you have already done. There just isn't enough information yet to be able to provide much advice! :) - Stuart -
