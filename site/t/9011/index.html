Goodday good people! Iam currently building a new studio and because its a old building with half meter of concrete between rooms iam considering alternative for 2 way visual communication between producer and artist. Iam thinking 32" tv screens are fairly cheap, and some kind of camera connected preferably through a system where i can change between rooms and send too minimum 3 different 32" lcd tv-screen. need 2 way communciation between drum room and main room(2 lcd screens) Control room - main control room - drum room. This makes 4 lcd screens, and 3 feeds sent too 4 screens Does anyone have any experience with this kind of communciation in studio? What kind of system is it possible to get to achive this? gullfo25 June 2007#2
you probably need to start with about 5500 euros for the equipment which will likely be centered around a decent quality video/audio matrix switch (could be 1000 euros+) which you likely need folded into your normal talkback setup. if you have a dedicated pc with some type of video matrix software (not sure it exists), you could potentially use web cams but the 32" lcd screens are still fairly costly (~800 euros each for a decent brand) some examples: http://www.21best.com/21_best/electroni ... ale_7.html it gets more complex it you want multiple images per screen so you'll need some sort of video mixer to get to that level.
