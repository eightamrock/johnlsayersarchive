Looking good, Marc! Except... The hinges on that door are on the "up" side of the slope... Are you going to be able to open that door all the way without the bottom outside corner of the door coming into contact with the uneven patio slab? If not, I fear you'll damage the door or its seals and/or reduce clearance, since your 32" doorway will only allow about 29" to 30" with the door open at 90 degrees. Please share any "NEC surprises" you learn about!
Already got one, have to confirm actual "surprise" and solution then post the concern in appropriate thread. Concern is recessed lights in a cloud or other DIY acoustic contraption and type of wire used to run lights. Code is that wire can not be exposed must be behind drywall, in conduit, etc... Part of recessed light code is that if light fixture has a separate connection box or J box (which is attached to light assembly) then the wire which runs from box to fixture must be armored cable, this is how they come out of package. Also note armored cable is typically used to make last part of run from wall to a water heater and other spots in a typical house because it bends much easier that rigid conduit. SO I'm going to suggest that the recommendation for wire type inside a cloud or other DIY contraption should be armoured cable rather than NM (regular) cable. AND care should be taken to use the correct gauge wire to match the rest of circuit lights are connected to. Marc
