welcome! it would help if you could read the "read me before posting" sticky to address a whole set of questions esp since its sounds like you need isolation and want to maximize that. in general, using additional layers of mass will be a better option but you should consider the decoupling options - like isolation clips and hat channel to support it (walls and ceiling) or using separate isolation walls decoupled from the exterior or other walls.
