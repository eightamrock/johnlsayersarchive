TomM8 March 2006#3
The digilink cables when connecting two digi I/O boxes or another box shouldn't be longer than a foot and a half. The cable between the computer and the first I/O box can be longer... I don't get it either, but that's what the manual says! From digidesign.com answerbase: What is the maximum length supported for the Digilink cable? - 50 ft. is the maximum cable length between a HD Core or Process card and the interface at 192 khz. Any expansion interfaces must use the 1.5 ft. (18") cable that ships with the I/O. Going beyond the 18 inch cable between I/Os is definitely not tested nor supported at 192 kHz. - 100 ft. is the max cable run between the HD Core or Process card and the interface at 96 kHz. Again, any expansion interface must use the 1.5 ft. (18") cable that ships with the I/O if the primary is using a long DigiLink cable.
