J-Texas wrote:
1 - Nails/screws to hold the 3/4" + solid core / lead sandwich together?
for a solid core 1 3/4" door with 3/4" plywood - trim screws 2 1/4" length will be fine.
2 - You said that you wouldn't count on a 300lb. door hanging on a 2x4 that would eventually sway... how would you frame it then?
If you want to isolate a double frame wall asembly then I would not build the walls with less than 2x6 (ut then again - I always design with 2x6 24" o.c. - which (forma board foot point of view) is almost identical to 2x4 @ 16" centers. If you build with 2x4's - then the door frame must run though and connect both walls.
3 - In figure 5.3 of the splayed window construction, you show the horizontal layout... should I assume that the vertical edges will be treated the same way? (neoprene, glazing tape, etc.?)
All 4 sides are the same........ Rod
