Soundman202030 July 2012#4
It looks a lot like pegboard to me!
Yep, it sure does! Poor man's perforated panel.
If it is, would there be any benefit to filling in some of the holes to create a binary sequence similar to RPG's BAD panels?
Not really. Perf panel works on the percentage perforation, panel thickness, hole diameter, and cavity depth, so I don't think you could also make it into a binary diffuser.
Where is the best place to hang clouds in a room of this size, and is there a percentage rule or any other guidelines?
Clouds are absorption, so they will be most effective where velocity is high and pressure is low: meaning "not right up against the ceiling, but space a bit away". But there's no specific location that is "best", since they aren't really tuned devices.
My final question is how to use REQ Wizard in a tracking or live room. Everything I have found is about testing your listening locations, but for a tracking room, I would think you would want to test lots of spaces to find the best places to put mics, etc. So where should I place the speaker and the microphone to get some basic ideas of the acoustics?
If you want to check the modal response, then put the speaker in one tri-corner, and the mic in the diagonally opposite tri-corner. That will excite/detect as many modes as possible. But if you are just after general acoustics, then set up the speaker in a typical location where you might put a large instrument (eg, grand piano), and the mic in a typical location where you might set a room mic, for picking up ambient room sound. Yeah, I know: that doesn't help a lot! :)
