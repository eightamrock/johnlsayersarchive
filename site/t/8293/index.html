Sketchup tutorial?

Started by jwl on 27 February 2007. 2 replies.

Originally posted at johnlsayers.com, topic 8293.

jwl27 February 2007#1
OK. I want to learn sketchup. Anyone have any good tutorials for how to use it for buildings? Most of the stuff I've seen tells you how to draw things that aren't rooms. I've already downloaded a few .skp files and plan to start playing with them, but that only gets you so far. I want to learn how to draw things from the ground up.
gullfo28 February 2007#2
check out the http://forum.sketchup.com/ site for ideas. if you want to take it to the next level, like building design, etc. I recommend any of Frank Ching's books on architecture and building construction illustrated. this will give you the design details on framing etc. that you need to visualize to bring in more detail. the rest is practice... other than that, most tutorials I've found either deal with specific types of object creation (how to draw X), basic use of the tool, or high-end rendering techniques for architects and designers.
jwl5 March 2007#3
