gullfo4 January 2008#2
just draw a rough sketch by hand on paper with accurate dimensions - include doors, windows, pipes, ducts, columns, etc. photograph it and post it. or using the sketchup pencil tool, just draw lines based on the rough drawing - they can be to scale in sketchup - and you'll have a perfectly workable 2D floor plan. use the construction line tool to designate ducts beams etc. and the text label tool to point out salient features. keep it to 2D. it shouldn't take too long if you keep things simple. meanwhile there are numerous videos on YouTube regarding using Sketchup.
