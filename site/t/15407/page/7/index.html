Soundman20204 March 2013#152
Before you put any treatment in there at all, run an analysis with REW! You need that as your "baseline" data, so you can see what each part of the treatment is doing, and whether you are going int he right direction. So before you do anything involving treatment, download REW, set up your speakers and measurement mic at the final mix position, and measure the location of that mic very accurately! You need to be able to get it back to the exact same position (accurate to within a few mm) every single time, or subsequent measurements. Then after you install each part of the treatment, measure again with REW, and compare the graphs. - Stuart -

Soundman20205 March 2013#155
I'm having to get every thing in the live room first so that I can then move the bands kit in there before treating the control room, so are you talking about the live room or control room, or both?
Both, but the control room is more important. The basic concept is that the control room should have a "neutral" sound, not coloring the sound emitted by the speakers in any way, so that what you hear in the room is exactly what the speakers are telling you. On the other hand, the live room can have "character", subtly altering the natural sound of the instruments, if that's what you want to do. So a room can be more "live" or more "dead", or it might be "warmer" or "mellow" or whatever else you want it to be. And if you are not aiming for any particular sound, then at least you want to make sure that there are no gross problems with the room that might need treating. IT doesn't have to be neutral, like the control room, but at the same time you don't want major imbalances in the sound. That's my long, convoluted way of saying "test them both, but the CR is more important". :) - Stuart -

For my live room I am planning on building a cloud to hang from the ceiling , should I make it open backed or hard backed?
simo12 March 2013#158
Hi Roguejackal, I'm not an expert, but browsing around the forum I collected the following info: - Use the open back cloud for suspending insulation off an already angled ceiling, so the insulation works on lower frequencies than if just placed directly on the ceiling. It helps with modal issues, tempering the floor-ceiling response. - Use the hard back cloud for breaking up the modes / flutter between floor and (a flat) ceiling - angling also provides a more broadband effect than simply making it flat.. Insulation in your clouds will not affect lower frequencies - an angled hard top cloud will. Hope that helps (and if not true, I hope an expert will correct it !) Your build is coming together very nicely ! Simo

Soundman20202 April 2013#171
Before deciding on whether or not a hard back would help, it would be good to run REW on your room to see what the actual acoustic situation is, and whether or not the hard back would do anything useful. If you can, run one set of tests without any treatment in the room (just the hard inner-leaf), or as close as you can get to that, reasonably, then install the treatment devices, one at a time followed by a new set of tests, so you can see exactly what each devices is doing, and what still needs to be done. There isn't really any fixed height that one can say "It must be exactly 11 5/17" from the ceiling", as that depends to a certain extent on the room and what it needs. But probably hanging it around where it is right now is a good starting point. Once again, experimenting with different heights and angles using REW can reveal a lot about the room, and how the cloud is working in it. - Stuart -
