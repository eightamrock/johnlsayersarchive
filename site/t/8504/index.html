sharward28 March 2007#5
If you running an oversized air conditioner, you run the risk of "short cycling," meaning the system cools the room in short bursts. This leads to inefficiency (the system runs more efficiently when it is allowed to "warm up" to an optimum level) and comfort fluctuations. But perhaps more importantly is humidity build-up, as the system can only dehumidify the air when it runs for a while. This is more than just a comfort issue -- overly humid rooms can lead to mold growth, sometimes toxic. Bigger is not necessarily better. Properly sizing a system is critical for efficiency and effectiveness. --Keith :mrgreen:
