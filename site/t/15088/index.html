gullfo16 December 2010#15
here's what i recommend to novices with CAD programs - start simple. create a "to scale" floor plan showing all the doors, windows, pipes, obstructions, etc etc. and add some comments on things above like beams and ducting etc. include photos of the space so we can see things directly (if the space exists). don't try to load up lots of components or get fancy with the 3D stuff because it can take a while when you're starting out and really we want to have a communications vehicle more than a polished CAD file.
