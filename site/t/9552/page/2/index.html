gullfo20 November 2007#30
if it were me, i'd tear down the existing control room walls and start fresh armed with the knowledge of proper room ratios, good isolation techniques using common construction materials, and some clever ideas to make the window based AC into something to cool the whole place and not create a lot of noise. check out Rod's book on home studio construction where he has ideas on building a "cool room" to leverage a window based AC unit to feed the rest of the space via ducts. you might not need a large "room", a box might do it instead. or maybe saving some money by doing it yourself, invest in a split unit AC and exchange unit to get serious cooling.
