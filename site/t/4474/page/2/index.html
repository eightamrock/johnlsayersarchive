Not necessary; you can use an adaptation of this method http://www.johnlsayers.com/phpBB2/viewt ... 3&start=30 (check my post on Nov. 8) And just use slightly thicker than stud depth, retained against the gypsum by the strapping across the studs. If you're using wood studs, build the frame on the floor first, fasten the strapping across the backs of the studs using large head roofing tacks (at least 1" long) then stand the frame up, fasten in place, insulate, and put the gyp layers on...
