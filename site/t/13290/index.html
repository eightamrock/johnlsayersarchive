Hi y'all It's been awhile since my last visit here. I got my studio up and running but it has come to the point when I need to move my studio to a new location. Luckily I have found a new place! I went to see it today and took only some rough measurements so the drawings below might not be dead accurate. Anyway, it seems promising enough and I'm excited to be doing this all over again, hehheh. :wink: The new place: Located in a top floor(5th) of a commercial building. Most of the building is vacant. There is some sort of press on the second floor but it doesn't affect the top floor at all noise wise. On the top floor there are pretty much only some storage spaces so no problem with that either. The studio space would be L-shaped since it's in one corner of the building. The room hight is 2,7m and since it's the top floor there's nothing above but the sky. All the interior walls are the usual single layer gysium board-type. The total usable space would be around 70-75m2. All the outside facing walls have big office-type windows from wall to wall so that's going to be something to think about. We would like to leave the windows exposed in the live room but we will hang some heavy curtains. In the CR we would like to have as much scenery as possible so at least some sort of window outside would be nice. The same goes for the other rooms. We would like to use the existing interior walls if only possible. The only problematic thing about the space is a large concrete pilar/coloumn (approx 50x50cm) going from floor to ceiling in the corner of the building(room B in the picture). What we need: At the new studio we're going to need a control room, live studio, voc/amp booth, edit suite, a small lounge/storage. That's a lot of rooms for the space(approx. 70m2) we have. -Control room We would like to have a nice size control room, maybe 20-25m2. I have a 24ch soundcraft 6000 series mixer so it isn't going to be an issue but we would like to feel comfortable 8) -Live room The live room as big as possible... Whatever is left after everything else... The usual live room for tracking drums and maybe whole bands etc... -Vocal booth Vocal booth large enough for one person to feel comfortable in.(4-5m2?) -The edit suite Mainly for editing tasks(obviously) so it doesn't need to be too big. But it would be fantastic if the vocal booth could have a visual also to the suite so we could use the editing suite and vocal booth while tracking something else in the live room and CR. -Lounge This is for the bands to hang around... -Storage Maybe a simple 2-3m3 closet? The access to the studio space is from a hallway. Currently there are three doors leading in to the spaces from the hall, all of which can be covered. We would like to have maximum isolation between the CR and live room so no door between those two. Also we would like the vocal booth to be accessed from the hallway so traveling wouldn't disturb tracking in the live room. I don't know if that makes any sence but please ask if I'm missing something here(it's been a very long day and my head is not here with me). Also I just downloaded sketchup again and will have some kind of drawing up for you maybe tomorrow but feel free to suggest different layouts. Back to the drawing board.... -Tomi-
