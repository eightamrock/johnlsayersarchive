sharward12 November 2005#154
I've done some Googling in an attempt to find actual building code references regarding proper installation of multiple layers of drywall on a ceiling (or even on walls), and I'm coming up empty handed. This does not mean that code is silent on the subject -- it just means that I'm giving up my Googling for now. ;-) I would suggest calling or visiting (visiting is better) your local building department to see if you can get a definitive answer based on the model codes they are using and with which they are holding you responsible for complying. If there indeed is code that backs this up, then by all means, write down the code section number and the exact language in the relevant paragraph, and insist that whomever you have doing your work follow that code to the letter. That makes code the "bad guy" rather than you. And, of course, call the jerk who smugly made your "you're a musician -- I don't tell you how to play guitar" and edify him on the building code for which he should have more respect! If code is silent on the subject, then maybe our community can reconsider the recommendation. If we conclude the difference is negligible, then it may make sense to forego being a stickler on that point and allowing the contractor to do what is intuitive/comfortable. (Although the aforementioned "jerk" should not be reconsidered!) If code expressly prohibits rotation of multiple layers (doubtful), then we'll all know better... And then maybe the "jerk" should be reconsidered. And maybe not. ;-) In short, not knowing what code says (or doesn't say) makes the argument academic. Having the facts makes the argument meaningful and clears up the controversy. --Keith :mrgreen:
