xSpace4 June 2011#5
Remembering the shotcrete is a process, not a product, your answer will come from looking into concrete of the same thickness. In that respect, the thicker the wall being placed, the better the overall STC and Transmission loss values will be. The Urethane is more for the thermal envelop I assume since you would specifically not want to have this exposed, even that assumes that local code would allow this type of practice. Typically you have to install sheathing of some type after the insulation which requires a framed wall assembly. Could we see the design sheets on this project?
