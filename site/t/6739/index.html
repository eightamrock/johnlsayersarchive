len-morgan6 August 2006#12
DirkB, Almost every one of the corners in my studio had the "problem" you are asking about and I can tell you how I managed my corners. First, you want to make the wall structure as rigid as possible so what I did is laid out the bottom plates to meet each other at an angle, like a mitered corner on a picture frame. The top plates (you'll want two) cross each other so in your case, the first top plate would continue from the first wall section over to the top of the second wall. The second (top) top plate would continue from the other wall over to the first. It's a lot harder to describe that it is to do. :-) I would also ask (again) about whether these are load bearing walls? What is going to be holding up the ceilings of these rooms? If it's these walls, then they ARE load bearing. That term doesn't just mean holding up the second floor. len

Luftweg7 August 2006#19
Not sure if there is an issue with ceiling height, and/or an inability to use deeper section ceiling joists... But if you have to use shallower section depth joists, you might need to consider sistering 2 wooden joists together -- as has been suggested -- or using steel joists for the ceiling, or using the wood joists with steel tension flanges screwed to the bottoms of them... It would appear that steel joists (i.e., studs) of the appropriate gauge are far stronger than wood in the same given section depth; these can also be doubled back-to-back or boxed to gain more strength/stability(from twisting)... I speak of these things because I need to conserve ceiling space in my project, and this required a design with sistering and steel... Of course, if there is no real problem with height, then using a deeper wood joists might be the way to go.... K
