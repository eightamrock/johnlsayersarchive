How to wire a Combo Jack

Started by gdizzle on 31 July 2007. 1 reply.

Originally posted at johnlsayers.com, topic 9192.

gdizzle31 July 2007#1
I've got some wall plates with the Neutrik Xlr/TRS combo jack. Its got like 8 pins to solder. Does anyone know how to wire this up to a standard XLR cable?? I plan to use one jack for a mic (XLR), and the other for headphone send.(1/4) gd
Aaronw1 August 2007#2
Which part # is it? If it's the one I think it is, here's your pin out... For XLR: Use Pins 1, 2, 3 For 1/4" TRS, Use Pins: T, R, S The one's w/ "N" after it is for normalling (eg: TN, RN, SN) You shouldn't need to wire the "N" pins.
