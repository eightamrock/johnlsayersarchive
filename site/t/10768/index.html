I also use the room for band rehearsals as well, with the main focus still being drum tracking. The room currently sounds pretty bad. There are a few areas of concern that I have that I'm really not sure how to handle. I may have access to some OC703 but may have to use Rock wool. Any help or direction that could be provided would be very helpful. I've provided as many accurate measurements and placements as possible and have done the diagram to scale in Microsoft Visio. I would like the room to be well balanced, and not too dead sounding to be able to capture some good drum sounds. EDIT: All flooring is faux-wood laminate. This detail was not in the diagram, sorry!
