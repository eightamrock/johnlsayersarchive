I'm curious if there have been a lot of designs on the site that were more geared towards someone who's recording themself? Do I build a particularly "live" control room that also allows for tracking? the dreamer19 January 2005#2
hi, i'm planning to do the the same, i want to be able to record myself from the booth. it's no problem to put a daw remote there. there are remote solutions via CAT5 available, if the booth is close to the daw you don't need that. take a monitor/mouse/keyboard splitter to controll 2 computers with. thats all. next point: you want a controllroom as quiet as possible: -computers in an extra machineroom or ventilated box. -ability to turn off ventilation system for very sensitive sessions. etc..... i'm sure you want to record yourself in the CR too! below you see a pic from cavell studio with integrated DAW-Remote.
