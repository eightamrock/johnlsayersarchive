jamesway - first you have to set the scale View/define Rulers and Grid. Then when you draw a rectangle you can right click and select "position and size" and enter the dimensions of the object. If you click on shape properties you can determine how an object expands so if you make it horizontal the object will only expand in one direction. It's all about geting in there and playing with it. ;);) cheers john
