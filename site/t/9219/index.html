maybe a modification of John's single garage design would work? i'd use inside-out walls to get the treatment and isolation. you can use routed plywood for slats if 1x or MDF is not readily available. on the back of the CR i'd make it dead since you don't have a lot of depth there but i'd put in a false ceiling and make that dead end, live front with absorption behind it.
