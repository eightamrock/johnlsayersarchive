xSpace20 February 2010#8
Hey, In answer to the Styrofoam question, it really has little ability to do anything except for some thermal properties. It has no mass and may even rattle so much that it creates a problem if it was not glued to the surface...but it just has no value here. You should use regular fluffy insulation if you are trying to damp down this door. Garage doors require some attention to detail since they are basically the same as a closed door with poor seals...only bigger :)
xSpace20 February 2010#9
One more thing...unless you guys have some real skills...tearing down walls is not something that should be done simply to open up space. In a block building as often as not, this wall is supporting something overhead. These are the questions that only you guys can answer. If it is a support wall of >anything< then tearing it down without taking that support of the above into consideration can be a harmful concern Pictures?
