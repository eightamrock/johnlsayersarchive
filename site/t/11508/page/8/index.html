Soundman202016 June 2010#188
1) I know its been debated, but if I have extra left over insulation, should I fill the cavity spaces between rooms with it?
Yup! Rod did point out that there might be fire code issues with that, but from the pure acoustic isolation point of view filling the cavity will gain you better isolation. So if you need better isolation, and your code allows you to do it, then go for it!
2) I know its not kosher to use resilient channel on a double studded wall, is this rule the same for a double studded ceiling? I would think so?
It won't gain you anything. If the wall is already decoupled, then it is already decoupled! decoupling it again with RC won't gain you anything additional (except for the slight extra depth of the RC itself). - Stuart -
