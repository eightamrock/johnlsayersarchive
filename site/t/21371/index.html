Soundman20204 January 2018#2
Hi. Please read the forum rules for posting (click here). You seem to be missing a couple of things! :) That said, there's a lot wrong with some of those images that you found. For example, the first one shows flex duct tightly packed inside a wooden box, completely kinked and bent: That's just silly! Flex duct should only ever be used stretched out in s straight line, or gently curved following the manufacturers recommendations for minimum radius, and using suitable support saddles. The result from doing what that photo shows would be a disaster: a very noisy disaster, with insufficient air flow, causing the fans to over-speed and burn out way before their useful life. The correct way to do silencers, is like this: viewtopic.php?f=2&t=15430&start=45 viewtopic.php?f=2&t=1929&start=74 viewtopic.php?f=1&t=11542&start=5 viewtopic.php?f=2&t=9761&start=0 viewtopic.php?f=2&t=11485&start=98 viewtopic.php?f=2&t=11508&start=157 viewtopic.php?f=2&t=13821 viewtopic.php?f=1&t=15378&start=44 viewtopic.php?f=2&t=18202&start=16 Those are examples of silencer boxes built by forum members. For the fan itself, my clients seem to have had good success with the Fantech RVF units that are specifically designed for this application, such as this one:
Image not preserved: Fantech-exterior-exhaust-fan.jpg
The RVF 4. 4XL, 6, or 6XL, work fine. For a vocal booth, you probably wont need more than the RVF4, unless the booth is very large! Get the variable speed controller as well, so you can slow it down to whatever rate you really need, as even the RVF-4 is a bit big for a booth, running at full speed - Stuart -
