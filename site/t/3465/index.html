dkatz4224 March 2005#1
I'm putting together a studio with three rooms (live, booth, CR) plus an equipment room, and would like to be able to dim the lights in each room individually. As an optional added bonus, I'd like to be able to control all of them from the control room. I've been digging through the Lutron Grafik Eye specs trying to see if I can pull off what I would like. It looks possible. Assume that each room is one zone. One of the available wallstations (SG-4S) has four scene selection buttons and a master up/down button. It appears by looking at one of Lutron's application notes that you can trick the system into dimming an individual zone by setting a scene that has all other zones set to "unaffected"; then you can vary the master level and it will only affect the particular zone. Has anybody tried this? The only downside I see to this approach is that if anybody hits the off button in one of the rooms, all of the lights in all of the rooms will turn off. Anybody out there with a Grafik Eye doing anything like this? Another possibility might be to use one of the Smart Dimmers (such as the Maestro.) It appears that the way these units work is that the master dimmer has the triac; then one of the travellers carries the power to the load and the other carries a communications bus. Additional remote units seem to only pass requests over the comm bus back to the main dimmer. This implies that I could put the main dimmer for each room in my equipment room (away from the tracking rooms and hopefully not spraying too much EMI) and then put a remote unit in each of the rooms. Anyone with any experience on how noisy the smart dimmers are? Any other ideas on how to approach this problem? Thanks...

Aaronw wrote:

One of the slick things about the smart dimmers is that they're all 3way (actually 4way). All but one of them don't actually do anything except talk to the first one, which sits at the line end. You use 14/3 (a bit easier to handle than 12/3, which is overkill) and one of the conductors carries the power regulated by the first unit, which is passed along through all the others to the load at the far end, and the other conductor is the communications bus so that all of the units can control the light level. With standard triac dimmers you can only have one dimmer; the rest have to be 3way or 4way switches. I imagine that you could use multiple variacs on the same circuit, but they would be subtractive (each dimmer could only make things darker; to make it bright you'd have to turn up all of them.)
