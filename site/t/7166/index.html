If you are building a double 2x4 stud wall with a 2" space between below a small attic space ie the coller ties are the joists above the walls. the walls are approx 7.5' tall 1) do you need to fire block the space between the walls( I realize this may be a local code issue) but if you do how do you create the block without short circuiting the double wall? Luftweg27 September 2006#2
There is a description and picture on how to avoid 'shorting' the 2 walls in Rod Gervais' book: http://www.amazon.com/Home-Recording-St ... 1598630342 There are apparently several ways this can be accomplished. Basically, it seems you use solid fire blocking products like gypsum board solidly supported to one wall's (leaf's) framing; this should overlap the other leaf's framing (bridging the dead air space) -- but still leave a narrow gap, so that the gypsum doesn't actually touch the other leaf's framing. This gap is packed with rockwool. Finally, seal the ends of the gap with fire caulking.
