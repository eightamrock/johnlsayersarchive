knightfly22 February 2005#2
Colin, it's not obvious from the reference materials we have posted, but acoustically, carpet (when used between layers of mass, such as plywood, gypsum, etc) is considered AIR - so your construction idea would create a mass-air-mass-air-mass (or worse) partition, which would suffer quite a bit in the low frequency isolation. Another problem is that carpet likes to be a good home for dust, mites, mold, fungus, etc, and should NEVER be placed in a location where it can't BREATHE. As far as using plywood, you would just need to use MORE of it - if 2 layers of 5/8 gypsum would work, it would take 3 layers of ply (including proper SEALING of each layer's cracks, etc) to get about the same result. If you've not already read the very TOP announcement in this forum, it will lead you to an understanding of general concepts of isolation that will help with a lot of your questions... Steve
