hey there I've been working on some plans for a Music school / studio. :shot: I just don't know all the requirements for the specifics of the designs. So I would like to ask for any input on improving current plans. Luckily nothing has been built so far, so yeah. Unfortunately due to various reasons, I cannot reorganize the rooms to get a different layout :-( But I like this layout, and I think it will work nicely. ok here are the specs and my thoughts. Room1 = 3.12m x 4.19 x 2.2m tall Room2 = 5.97m x 2.68m x 2.2m Room3 = 4.53m x 5.76m x 2.9m tall Room 1 - Recording room / class room Room 2 - Control Room Room 3 - Recording room / band performance & class room Why I put the desk in that specific place in the control room is so that from the same position I would have a clear view into room 1 & 3 which are both, recording rooms, and also to have the monitors play into the length of the room, which I heard is better than having it play into the width of the room. Also it's to have 2 different environments with different characteristics, and then I can record in each room without changing position away from the monitors and the workstation. The door at the back of room 2 is only and emergency exit and there won't be any traffic of people there behind my desk. If it'll work I can probably put in a bigger window between rooms 1 & 2, so it would be even easier to see into room 1 from room 2 if you aren't in the 'driver's seat', people then wouldn't have to lean over my shoulder to be able to communicate with someone in the other room. I know the access from room 1 to room 2 isn't too easy, but I didn't want a door leading straight into the control room, because of the fact that I might just rent out that room to other teachers, and then they would have access to my control. So it's just a way to keep the control rooms privacy. If it works this way, then I keep the drums set up for recording and leave it that way, then it save the time and effort of having to set up the mics and other equipment, for recording. If someone wants to bring in their own kit to record on, then luckily I have enough space in room 3. The other rooms in the building, are rooms I rent to people who wants a venue for teaching. I'm also a guitar teacher, and so I would most likely be using room 3, although there are always exceptions, and I have to prepare for them. So please give some input, and some suggestions if anybody can think of some ideas that would make the life in the studio better. And I'm wondering, (excuse me if this is the wrong place to ask this) How 'dead' should rooms 1, 2, and 3 be? Room 3 would be my live room, and room 1 is gonna be a bit more 'deadened', and then I would have some acoustic panels which I can move around to change the characteristics of the recording environment, when needed. But how about the control room? How 'lively' should that room be? :? Thanks in advance for any suggestions and help :D Ruvann
