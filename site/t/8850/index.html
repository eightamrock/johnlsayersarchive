kendale16 June 2007#4
Aloha, I'm not sure if there is a "normal" height where you are, but I've seen it range from 8' to 12' out here. In any case, a 9' ceiling will work very nicely. Given that figure, you could use any one of the following ratios to determine the rest of your spaces. In Rod Gervais’ book “Build it Like the Pros,” http://www.johnlsayers.com/phpBB2/viewtopic.php?t=5670 he points out both L.W. Sepmeyer’s & M.M. Louden’s formulas most widely used in professional studios worldwide. He also notes that the orders listed are (top to bottom) the first to third best ratios in both cases. L.W. Sepmeyer Height Width Length 1.00 1.14 1.39-------------9’ x 10’2” x 12’5”’ 1.00 1.28 1.54 1.00 1.60 2.33 M.M. Louden Height Width Length 1.00 1.40 1.90-------------9’ x 12’6” x 17’1” 1.00 1.30 1.90 1.00 1.50 2.10 That should be a good place to start. Hope this helps, Aloha 8)

gullfo15 July 2007#13
the fronts of the soffits are mostly solid, the middle maybe more or less solid or absorptive (less absorption (except very top or bottom) is probably better in this design)... from a mode design - i'd ignore the soffit depth because the room volume is going to matter more than exact "golden ratio" and the trapping behind the soffits and center are going to alter the modes in the room beyond simple mode calculations... it is possible to overthink the design on ratios alone :? the little bit of symmetry difference in the trapping "could" matter but not nearly as much as if the asymmetry was present in the listening space so i'd wouldn't be too concerned there. if you didn't want to soffit, you'd still build the front wall (slat resonators... 8) ) on an angle so its "square" with the room... it looks like a good design... smaller file size - just make sure you select Model Info -> Statistics -> Purge Unused to clear unneeded textures and objects (they can build up quick!)

gullfo18 July 2007#15
i'm not sure if sketchup can calculate the volume or complex volume. a consideration on soffits is the type of monitors you have - are they suitable for soffit mounting? also, what size/power are the monitors? they need to work within your space and soffits might not be readily positioned to place the monitors in your space. for example, you might need more or less distance or angle on the monitors to get them positioned, and you have space limits which may preclude soffits. that said, if you will soffit mount them, then build the walls. if they need to be on stands (or worse, the console) then build flat and use corner bass trapping.
