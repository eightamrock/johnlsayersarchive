tmix13 March 2007#4
Gullfo posted exactly what I was trying to do. I ran into some issues of findind wood straight enough to work down the length of my long (32 ft) wall. I opted for similar solution of mounting 3/4 metal conduit clamped to the wall every 64 inches with a 3/4 thick block of wood and a conduit hanger. I then attached slightly bent open conduit hook type clamps to the top edge of my panels so that I could hang / move / add / subtract / switchout absorbers for diffusor etc. So far it works wonderfull. The ONLY drawback is the coduit rings ever so sligtly when struck. I guess there is a chance it may need to be deadened by shoving something into the ends if it tries to sympathetically vibrate with something in the room. So far mine is fine.

sandledfoot24 July 2007#11
I have been contemplating the same ideas and problems regarding mounting and hanging 703 panels. luckily, i've seen a professional product in person which uses 703. upon examination, i found they mount anchors by using an epoxy that soaks into the fibers then hardens creating a firm mounting point for that screw or hook. the actuall method i think would be to take the back of the panel face up, mark screw placements, pour a small amount of epoxy into a 1.5-2" radius, and then set the screw or hook, leave it there until it cures. it seems to be a fairly easy solution. I plan on trying it out, just haven't found the appropriate epoxy yet. (I can get some pictures if needed.) kevin (hope this isn't considered corporate espionage!)
