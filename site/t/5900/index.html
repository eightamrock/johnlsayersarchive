SonicClang27 March 2006#2
Yes it's 16 inches on center. If you measure between the studs you'll see about 14 inches. To make them staggered, make the first set of studs on one side half the regular distance apart.
knightfly27 March 2006#3
You'll get better low end TL using 24" centers - each side's studs are on 24" centers, with the OTHER side offset 12" - the finished frame before wallboard looks like 12" centers from the side, but it's 24" each side. When placing insulation in this type wall, do NOT give in to the temptation to "weave" the insulation through the studs sideways; instead, you want full R11 batts run vertically in each bay, with the opposing stud pressing the insulation slightly into the wallboard. This causes slight compression of the insulation, which damps the wallboard panels and ALSO improves sound Transmission Loss thru the wall. HTH... Steve BTW, if you have the room a full separated double frame wall will give better isolation than a staggered stud frame.
