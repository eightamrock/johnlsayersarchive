I would like to put an external window in my studio, described here: http://www.johnlsayers.com/phpBB2/viewt ... highlight= The window would be in the isolation room, and would let some light in through the control room window. I discussed with my contractor friend about building the window from scratch similar to the control room window, and he had serious concerns about moisture and condensation inside the window due to temperature differential between inside and outside. He said manufactured windows deal with this with weep holes, etc. I've also considered getting something like a Milgard Quiet Line Window (which claim STC of 47), then building a hinged plug/door as described elsewhere on this forum. Any ideas on the best way to build an external window while keeping isolation values as high as reasonably (budget) possible.
