AndrewMc25 August 2003#4
I just had HVAC installed a few months back in my studio currently under construction. I have a return in the control room, the studio room and the entry soundlock. It's all flexible ducting and all the returns and all the feeds have their own runs back to the blower unit - It's absolutely silent. You should be able to run some 12 inch flexibles back to the return air and have the filters in the return register.
