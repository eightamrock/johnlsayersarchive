gullfo10 December 2010#106
yes, basically two (2) strips of 2x2 attached on the walls 3'6" apart and a 4x8 sheet of 1/8" plywood bent into the space (which is about a 7" deep bend). if you feel the need, some pink insulation lightly packing in behind will add some additional absorption and damping. if you're going to add several polys, change up the sizes: 4'x4', 3'x'8' (in 2'9" spaced strips) etc. giving a rip down one edge (say 1/4") of the 2x2 on a 60 degree will add some additional security for holding the plywood.

looking good! hopefully you remembered to clean the inside of the glass before installing it... :twisted: the slats would need to be enclosed and sealed etc to work correctly so I'd just go with as much absorption as you can on the back wall and still leave a space for the couch (remembering the couch as some depth so i'd build out as far as possible...). and just use the slats to preserve some HF. worst case later you find you do need to build some tuned slats or membrane traps to fix some problem frequencies - you can readily do that.
