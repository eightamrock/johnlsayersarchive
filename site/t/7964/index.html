orangenumerik17 January 2007#2
Alexidoia Why do you want to angle your windows ? I don't have any info on how the rest of the wall in wich you plan to put this window is built. But my guess is that you'll get better isolation by not angling them and placing them as far as you can from each other. Also what kind and thickness are they ? All of this is a moot point if you plan using 1/8 glasses or worst double thermal glasses in a single partition wall. But if you still want to angle them, then a 6 degres angle should be considered a minimum. You'll get some control from early reflections from the windows and avoid visible "ghost" reflection between the windows At the expense of some isolation. One option would be to angle only one of the two window...food for toughts....
