Hello all, I have been lucky enough to aquire my ultimate building for a studio, a reasonably sized church from 1895. There is an addition to the original church built in 1949 which contains a basement with 9'+ ceilings and roughly 1500 sq ft to play with for technical studio rooms. The Sanctuary space will remain open as it is today for use as a single recording room when needed. I want to build two control rooms and two recording room along with a computer room in the basement space for the main studio area. There is also a kitchen that will be made into a lounge and an existing bathroom. There are two entraces to the basement, one directly from and outside staircase and the other from the main stairwell. I'm just getting started on the design phase and would love some input on the layout and anything else you can think of. I do have lotsa pics and will be posting them as it moves along. Here's a simple floorplan layout that I've been working on so far. Thanks in advance for any input. -ashley
