John Sayers15 October 2006#3
Consul - everytime you add a component to sketchup it gets stored in the file EVEN if you don't end up using it. Go to Window/Model info/Statistics and purge unused. It will remove all the components and materials that aren't being used in your model and the file size will change accordingly. cheers john
