dymaxian30 August 2004#3
If you're building a new place from the ground up, and you've got that much space, I'd think you'd want to use double-walls instead of a single wall with RC on one side. The isolation of that sort of system is far and away better, especially if they're mounted on isolation pads that will keep structural transmissions down. Chances are you've gone thru the Studio Construction part of this forum, but if you haven't, that's where you need to sit down and have a good long read. Good luck!

knightfly31 August 2004#8
Sam, if you'll be using separate frames for each leaf of a double leaf wall, then RC is a waste of time and effort - even in a single frame wall, using RC on one side does nothing for low frequency isolation, only mids and up (about 6-7 dB @ 500 hZ) - once you go to totally separate frames, the RC is a moot point... Steve

How do you select square cornered lines in Smartdraw?
they aren't lines - they are rectangles. Draw a rectangle say 1 unit high and 20 units wide. Then select shape properties(right click) and click "horizontal only" and the shape will stay the same height but have variable length;) cheers john
