Hi Kaj, Interesting idea. I've never personally had much luck with the hanger method. I've definitely never tried using MiniTraps as bass hangers. My suspicion is that it wouldn't work. The normal bass hanger design uses a rigid surface, with absorbent around each side. This is basically a gobo. The MiniTraps are velocity absorbers, which require sound to pass through it. It'd be interesting to test this out, though....
