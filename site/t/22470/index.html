SoWhat29 July 2020#3
Greetings birdy50, Given the heavy ambient noise considerations, you will want as much isolation as you can get. The room-in-a-room will work best. I would suggest that you start by determining how much available square footage you have to build your OUTER structure. Then Immediately get Rod Gervais's book Home Recording Studios: Build It Like the Pros and read it. Then read it again. Then you'll be armed with the information you need to ask questions. All the best, Paul
