So, I'm planning to build a basement studio when I've got the money. My basement is, for the most part, rectangular, but the area that I plan to build the studio is under the master bedroom, which forks out by about ten feet, and has a width of eleven feet. I plan to build the studio there, with roughly half of the studio extending into the non-enclosed area of the basement. That said, because it's to be built in an area constrained by pre-existing structure, width (11 feet) is non-negotiable. My budget for this project is $5000-$10000 for construction. The large rectangle containing the entire image represents my space limitations - 20' x 11'. An issue with this room is that since there are no right-angle corners, triangular bass traps won't fit properly, but I assume that can be offset by using a few more 4" thick rectangular panels. As has been stated, the basement is unfinished. There's the exterior concrete of the basement walls, the insulation, and then nothing. Ceiling is completely exposed.

jwl22 November 2007#2
I'm not good with drawings, but I have some suggestions. First, I'd rotate the setup 90degrees, one way or the other. You want the speakers firing into the long part of the room. Ideally, place the listening/mix position 38% back from the front wall. A room that size would be good for a one-room studio; if you record there is plenty of space behind you to set up the musicians. It'd be cramped but you could fit a band there. Are you planning on soffit-mounting the speakers, or will they be freestanding/on stands? If you haven't already, read around this forum. Buy Rod's book. Construction-wise, how important is isolation to you? If you need isolation, I'd consider John's inside-out wall design for the inner walls (you'll need to build double walls for good isolation) so you can incorporate acoustic treatment directly into the wall. You can use this design for the ceiling as well, though you'll have fairly low ceilings.... When I was designing a one-room studio for my garage, Kendale did a nice drawing for me on my thread. Check it out, it's a very similar size to what you have to work with.
