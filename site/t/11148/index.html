Soundproofing control room?

Started by Ciaran on 27 August 2008. 1 reply.

Originally posted at johnlsayers.com, topic 11148.

Ciaran27 August 2008#1
Hi all - hope I'm in the proper forum for this question. I'm planning to build a small studio in my back garden and a friend is doing up plans. I'd also like to have the studio as an occasional living space for friends staying over etc. My problem is that I'd like to have some natural light and not have all concrete walls with no windows. So I'm wondering - is there a need to sound proof a control room, or is it enough just to soundproof the live room? I'm thinking that tracks played back in a control room needn't be loud, just normal levels, so there's probably no need to soundproof it. This way I can have a window or patio door with glass to let in light into the control room. Does this make sense? Cheers, Ciaran.
