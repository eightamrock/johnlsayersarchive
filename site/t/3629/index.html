yoga8 July 2005#2
If you are thinking of doing an upgrade with your monitors, go all the way with it and get some of the newer model monitors, active if you can afford. The bass response and accuracy on a decent priced 1 X 6-7 inch monitor these days is alot better than the NS40m with it's 2 X 7 inch woofers. The size to performance ratio is pretty poor on the NS40m. You are better off with the NS10m if you are after translation, but if you are after bass response, NS40m will not cut it. If you cannot afford a proper upgrade, then stick with the monitors you have now, if you have already mastered how it sounds, because its not worth learning another monitor and taking up your own valuable time if it's not a better monitor than what you have in the first place.
