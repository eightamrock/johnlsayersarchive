rod gervais21 September 2008#4
shamca wrote:
Rod - is it common practice to create the inner framing shorter than the outer wall to permit angling the ceiling pitch? My max height is only 7.5'. Thanks, Shaun
Shaun, One has nothing to do with the other. If you have an inner ceiling frame that is independent from the existing - then it is common practice to install the inner wall shorter just to be able to rest the ceiling on the new walls - which effectively decouples them from the existing structure. In your case - you don't have enough height to slope the ceiling - probably not enough to make it worthwhile to develope a seperate inner ceiling frame - so your best bet would be to decouple the inner ceiling fromt the existing frame using resilient channels of some sort - and then to decouple the inner walls from that by leaving a slight clearance between the new ceiling and the top of the inner wall allowing for caulking to make the 2 airtight. Sincerely, Rod
