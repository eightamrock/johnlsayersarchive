John Sayers13 November 2006#2
It all about layers. You must place all the components of the model on different layers then you just show different layers on different pages. With the free version of sketchup I notice the "properties to save" items are unchecked on the pages dropdown. Make should you've selected all of them when you start working on pages. cheers john
leecow13 November 2006#3
Another key trick is to group everything that you want to function as a "thing". Studs, widgets, doors, wall assemblies ... anything that you may want to fiddle with later. If you don't do this, SketchUp will fuse together connecting surfaces making resizing of moving parts very difficult. BTW, this differs from making something a component.

gullfo13 November 2006#5
also, each view (tour pages) can be set to hide or unhide items and/or color/b+w/transparency. you can add things like sectional cuts and hide them on different views as well as John's suggestion to use layers (which is extremely useful because you can select subsets of objects). Grouping is good for unique objects but if you're going to use one or more on a given drawing (as well as building up your library) make it a component. this way you can globally change an object and its going to change them all. any components you want to leave alone, make it "unique" or explode then immediately use "group".

gullfo14 November 2006#7
you have to hide the object or the layer on the FIRST page then update it. then when you transition from page 1 to page 2 the new addition will appear. or going back to page 1 it will hide. the tour pages are simply views of the objects. adding objects will looking at a particular view will not make them hidden in another view (unless working with layers that are already hidden in another view- you would add the objects to the layer with Entity Info - right-click on object)
