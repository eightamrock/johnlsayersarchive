How this works

Each of the 2,500 candidate threads was auto-tagged into one of 12 topics by an AI pass. Your job: skim each topic's list, drop anything miscategorized or not worth keeping, move anything filed under the wrong topic, and pin 3–5 of the best entries per topic (these become the "key threads" linked from that topic's intro). Edit each topic's AI-drafted intro paragraph directly in the box above the list.

Everything you do is saved to your browser's local storage as you go, so it's safe to close the tab and come back. When you're done (or want a checkpoint), click Export curation.json and save the downloaded file as data/curation.json in the project folder — the Phase 6 site build reads only that file.

Thread titles link to the full rendered preview so you can read the actual thread before deciding.
